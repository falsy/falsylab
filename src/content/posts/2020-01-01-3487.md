<h3>1. Insert Query</h3>
<p class="basic-text-box">
  아마도 제 생각에는 지난 글 정도의 내용만 이해하셨다면 충분히 공식 홈페이지의 메뉴얼을 검색해서 진행하실 수 있을 거 같지만, 그래도 이왕 쓰기 시작한 김에 조금 더 적어보려 해요.
지난 글에서는 GET 위주 였는데요. 이번엔 POST, PUT API를 만들어볼까요?</p>

<pre class="legacy-code"><code class="language-javascript">// /router/index.js
const Router = require(&#x27;koa-router&#x27;);
const db = require(&#x27;../db&#x27;);

module.exports = () =&gt; {
  const router = new Router();
  const models = db.models;

  ...

  router.post(&#x27;/add&#x27;, async (ctx) =&gt; {
    const { name, content } = ctx.request.body;

    await models.boards.create({
      name,
      content
    }).catch(e =&gt; {
      console.log(e);
    });

    ctx.status = 204;
  });

  return router;
};</code></pre>
<p class="left-line-box">
  'koa-body' 패키지가 설치되어 있습니다</p>
<p class="basic-text-box">
  위와 같이 POST 라우트를 추가하였어요. body에 name과 content를 받아서 boards 테이블에 insert한 답니다.</p>
<p class="basic-text-box">
  정상적으로 잘 동작하는지 테스트 해봐야겠죠?</p>
<p class="basic-text-box">
  원래는 포스트맨(<a href="https://www.getpostman.com/" target="_blank" rel="noopener noreferrer">https://www.getpostman.com/</a>)을 주로 사용하지만... 그러면 또 스크린샷을 찍어야하는 번거러움이 있으므로 컬(curl)로 대신합니다.
터미널에서 아래와 같이 입력합니다~</p>

<pre class="legacy-code"><code class="language-text">$ curl -d &#x27;{&quot;name&quot;:&quot;falsy&quot;, &quot;content&quot;:&quot;hello world&quot;}&#x27; -H &quot;Accept: application/json&quot; -H &quot;Content-Type: application/json&quot; http://localhost:7777/add</code></pre>
<p class="left-line-box">
  컬(curl)에 대한 자세한 정보는 정광섭님의 글을 보면 좋아요!!
<a href="https://www.lesstif.com/pages/viewpage.action?pageId=14745703" target="_blank" rel="noopener noreferrer">https://www.lesstif.com/pages/viewpage.action?pageId=14745703</a></p>
<p class="basic-text-box">
  우선 -d 옵션이 있으면 자동으로 POST로 설정이 되고 JSON 형태의 데이터를 보내고 Header에 'application/json'타입을 적어주고,
마지막으로는 만들었던 서버의 URI를 입력해주었었습니다.
그럼 이제 DB에 데이터가 잘 추가 되었는지 DB에 가서 확인을 해보면,</p>

<pre class="legacy-code"><code class="language-text">+----+-------+-------------+---------------------+
| id | name  | content     | created_at          |
+----+-------+-------------+---------------------+
|  1 | falsy | hello world | 2020-01-01 09:38:26 |
+----+-------+-------------+---------------------+</code></pre>
<p class="basic-text-box">
  짜잔!</p>

<h3>2. Multiple Insert Query</h3>
<p class="left-line-box">
  멀티플 인설트 쿼리... 이게 맞는 영어 인지 모르겠습니다. 타이틀을 한글로 시작할 걸 그랬습니다...</p>
<p class="basic-text-box">
  여하튼 여러개의 데이터를 한번에 인설트하는 방법은 아래와 같습니다~</p>

<pre class="legacy-code"><code class="language-javascript">// /router/index.js
const Router = require(&#x27;koa-router&#x27;);
const db = require(&#x27;../db&#x27;);

module.exports = () =&gt; {
  const router = new Router();
  const models = db.models;

  ...

  router.post(&quot;/addList&quot;, async ctx =&gt; {
    await models.boards
      .bulkCreate([
        {
          name: &quot;blue&quot;,
          content: &quot;hello&quot;
        },
        {
          name: &quot;red&quot;,
          content: &quot;world&quot;
        }
      ])
      .catch(e =&gt; {
        console.log(e);
      });
    ctx.status = 204;
  });

  return router;
};</code></pre>
<p class="basic-text-box">
  위와 같이 'bulkCreate'라는 메서드의 인자값을 배열로 하여 여러 로우 데이터를 추가하실 수 있답니다.</p>

<pre class="legacy-code"><code class="language-text">$ curl -X POST http://localhost:7777/addList</code></pre>
<pre class="legacy-code"><code class="language-text">+----+-------+-------------+---------------------+
| id | name  | content     | created_at          |
+----+-------+-------------+---------------------+
|  1 | falsy | hello world | 2020-01-01 09:38:26 |
|  2 | blue  | hello       | 2020-01-01 10:01:20 |
|  3 | red   | world       | 2020-01-01 10:01:20 |
+----+-------+-------------+---------------------+</code></pre>
<p class="basic-text-box">
  짜잔!</p>

<h3>3. Update Query</h3>
<p class="basic-text-box">
  이제 마지막으로 업데이트는 아래와 같이 사용할 수 있답니다.</p>

<pre class="legacy-code"><code class="language-javascript">// /router/index.js
const Router = require(&#x27;koa-router&#x27;);
const db = require(&#x27;../db&#x27;);

module.exports = () =&gt; {
  const router = new Router();
  const models = db.models;

  ...

  router.put(&quot;/update&quot;, async ctx =&gt; {
    await models.boards
      .update(
        {
          content: &quot;hi, world&quot;
        },
        {
          where: {
            name: &quot;falsy&quot;
          }
        }
      )
      .catch(e =&gt; {
        console.log(e);
      });
    ctx.status = 204;
  });

  return router;
};</code></pre>
<p class="basic-text-box">
  대략 update 메서드를 사용하고, 첫번째 인자로 바꿀 내용에 관한 속성을, 그리고 두번째 인자로 대상에 대한 속성을 입력할 수 있답니다.</p>

<pre class="legacy-code"><code class="language-text">$ curl -X PUT http://localhost:7777/update</code></pre>
<pre class="legacy-code"><code class="language-text">+----+-------+-----------+---------------------+
| id | name  | content   | created_at          |
+----+-------+-----------+---------------------+
|  1 | falsy | hi, world | 2020-01-01 09:38:26 |
|  2 | blue  | hello     | 2020-01-01 10:01:20 |
|  3 | red   | world     | 2020-01-01 10:01:20 |
+----+-------+-----------+---------------------+</code></pre>
<p class="basic-text-box">
  짜잔!</p>

<h3>4. 외래키(foreign key)</h3>
<p class="basic-text-box">
  외래키.
이름만 들어서는 아마도 외국에서 온 거 같습니다. 어려워 보입니다.
저도 잘 모릅니다.
대충, 두개의 테이블이 이어주는 거 같습니다.</p>
<p class="left-line-box">
  대충, 조인문 쓰려면 필요한 줄 알았는데.
대충, 검색해보니 외래 키를 등록하지 않아도 조인 문을 쓸 수 있나봐요??
뭐든 괜찮아요. 전 조인문을 좋아하지 않으니까요.</p>
<p class="basic-text-box">
  일단 기존에 만들었던 'boards' 테이블과 연결해서 사용할 'likes' 라는 테이블을 만들어볼게요.</p>
<p class="basic-text-box">
  보니까 저번글에서 생략했던데..
이번엔 boards라는 모델값이 필요하니까 아래와 같이 만들었답니다.</p>

<pre class="legacy-code"><code class="language-javascript">const boardModel = require(&quot;./boards&quot;);
const likeModel = require(&quot;./likes&quot;);

module.exports = (Sequelize, sequelize) =&gt; {
  const boards = boardModel(Sequelize, sequelize);
  const likes = likeModel(Sequelize, sequelize, boards);

  return {
    boards,
    likes
  };
};</code></pre>
<p class="basic-text-box">
  그리고 모델은 아래와 같이 만들었어요.</p>

<pre class="legacy-code"><code class="language-javascript">// /model/likes.js
module.exports = (Sequelize, sequelize, boardModel) =&gt; {
  const likes = sequelize.define(&quot;likes&quot;, {
    id: {
      type: Sequelize.INTEGER(11).UNSIGNED,
      primaryKey: true,
      autoIncrement: true,
      allowNull: false
    },
    board_id: {
      type: Sequelize.INTEGER(11).UNSIGNED,
      references: {
        model: boardModel,
        key: &quot;id&quot;
      },
      allowNull: false
    },
    count: {
      type: Sequelize.INTEGER(11).UNSIGNED,
      allowNull: false
    },
    created_at: {
      type: Sequelize.DATE,
      defaultValue: Sequelize.fn(&quot;now&quot;),
      allowNull: false
    }
  });

  likes.sync();
  return likes;
};</code></pre>
<p class="basic-text-box">
  딱 보면,
'board_id'라는 컬럼이 boards의 id값과 연결 된 포링키가 된거쥬!</p>

<pre class="legacy-code"><code class="language-text">// likes 테이블이 만들어지는 쿼리문
CREATE TABLE IF NOT EXISTS `likes` (`id` INTEGER(11) UNSIGNED NOT NULL auto_increment , `board_id` INTEGER(11) UNSIGNED NOT NULL, `count` INTEGER(11) UNSIGNED NOT NULL, `created_at` DATETIME NOT NULL DEFAULT now(), PRIMARY KEY (`id`), FOREIGN KEY (`board_id`) REFERENCES `boards` (`id`)) ENGINE=InnoDB;</code></pre>
