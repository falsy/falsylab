<h3>1. Swift</h3>

<p class="basic-text-box">
  사실 대부분의 언어가 비슷하듯, 저에게 그나마 익숙한 자바스크립트와도 크게 다르지 않았지만
그래도 가볍게 한번 살펴볼까요?
</p>

<pre class="legacy-code"><code class="language-javascript">// typescript
// 변수
var a: string = &#x27;a&#x27;
let b: string = &#x27;b&#x27;
// 상수
const c: string = &#x27;c&#x27;</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 변수
var a: String = &quot;a&quot;
// 상수
let c: String = &quot;c&quot;</code></pre>

<pre class="legacy-code"><code class="language-javascript">// typescript
// 숫자
const a: number = 30
const b: number = 10.0
const c: number = 10.0</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 숫자
let a: Int = 30
let b: Float = 10.0
let c: Double = 10.0
// Float - 32bit 부동 소수점
// Double - 64bit 부동 소수점</code></pre>

<p class="basic-text-box">
  '나는 왕초보니까 그냥 정수는 Int 실수는 Double 쓸꺼다!'라고 적으려고 했는데,
(자바스크립트에서 number도 64bit 부동 소수점이니까)
  생각해보니까 이게 또 자바스크립트에는 없던 메모리 야무지게 쓰는 맛이니까, 필요로하는 데이터 크기에 따라 써주면 더 좋을 거 같아요!
</p>

<p class="basic-text-box">
  위에 저렇게 Int, Float, Double 3개만 적었는데 사실 더 많아요.
  Int8, Int16, Int32, Int64, UInt, Uint8, ... 등등..
</p>

<p class="left-line-box">
  만약에 나이를 담은 변수라면? 나이는 음수가 없으니까 UInt를 사용하고 UInt8을 사용하면,
  2의 8승이 256 이니까, 0살 ~ 255살까지 표기할 수 있겠네요!
</p>

<pre class="legacy-code"><code class="language-javascript">// typescript
// 배열
const a: string[] = [&#x27;a&#x27;, &#x27;b&#x27;, &#x27;c&#x27;]</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 배열
const a: [String] = [&quot;a&quot;, &quot;b&quot;, &quot;c&quot;]</code></pre>

<pre class="legacy-code"><code class="language-javascript">// typescript
// 딕셔너리
const a: {[key: string]: string}[] = [{ aaa: &#x27;aaa&#x27; }]</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 딕셔너리
const a: [String: String] = [&quot;aaa&quot;: &quot;aaa&quot;]</code></pre>


<pre class="legacy-code"><code class="language-javascript">// typescript
// 값 없음
let a = null</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 값 없음
var a = nil</code></pre>

<p class="basic-text-box">
  정확하게는 nil은 null과 다르다고 해요. 스펠링도 다르...
  (하지만 왕초보에게 그 정도의 차이는 중요하지 않습니다.)
</p>

<p class="basic-text-box">
  하지만 또 그냥 이렇게 넘기기에는 너무 성의없어 보일 수 있기 때문에,
  <a href="https://seolhee2750.tistory.com/10" target="_blank" rel="noopener noreferrer">https://seolhee2750.tistory.com/10</a>
  위 포스트가 아주 간단 명료하게 설명해주신 거 같아요!
</p>

<p class="left-line-box">
  null = 포인터가 가리키는 객체가 존재하지 않음
  nil = 특정 타입에 대한 값의 부재
</p>

<pre class="legacy-code"><code class="language-javascript">// swift
import Foundation

let str1 = &quot;123a&quot;
let str2 = &quot;123&quot;

print(Int(str1) == nil ? 0 : 1) // 0
print(Int(str2) == nil ? 0 : 1) // 1</code></pre>

<pre class="legacy-code"><code class="language-javascript">// swift
// 옵셔널
var a: String?
a = &quot;a&quot;
print(a) // Optional(&quot;a&quot;)</code></pre>

<p class="basic-text-box">
  해당 변수에 값이 있을 수도 있고 없을 수도 있다는 것 말하고, 해당 값을 사용할때는 저 옵셔널 껍대기를 벗겨야 하는 거 같아요.
</p>

<pre class="legacy-code"><code class="language-javascript">// swift
// 옵셔널
var a: String?
a = &quot;a&quot;
print(a) // Optional(&quot;a&quot;)

if let b = a {
    print(b) // &#x27;a&#x27;
}</code></pre>

<p class="left-line-box">
  이 부분은 직접 뭔가 개발을 해보면서 익혀야 할 거 같아요. 아직 어색하네요..
</p>


<pre class="legacy-code"><code class="language-javascript">// typescript
// 조건문
const a: number = 2
const b: number = 1
if(a &gt; b) {
  cosnole.log(&#x27;true&#x27;)
}</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 조건문
let a: Int = 2
ler b: Int = 1
if a &gt; b {
  print(&quot;true&quot;)
}</code></pre>

<pre class="legacy-code"><code class="language-javascript">// typescript
// 반복문(for in)
const a = [1, 2, 3]
for(d in a) {
  console.log(a[d])
}
// 1
// 2
// 3

// 반복문(while)
let b = 1
while (b &lt; 4) {
  console.log(b)
  b += 1
}
// 1
// 2
// 3</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 반복문(for in)
let a: [Int] = [1, 2, 3]
for d in a {
  print(d)
}
// 1
// 2
// 3

// 반복문(while)
var b = 1
while b &lt; 4 {
  print(b)
}
// 1
// 2
// 3</code></pre>

<p class="basic-text-box">
조건문 반복문도 크게 다르지 않고, 괄호만 사용하지 않는 정도의 느낌이네요!
</p>

<pre class="legacy-code"><code class="language-javascript">// typescript
// 함수
function a(b: string): string {
  return b
}</code></pre>
<pre class="legacy-code"><code class="language-javascript">// swift
// 함수
func a(b: String) -&gt; String {
  return b
}
let result = a(b: &quot;aaa&quot;)
print(result) // aaa

func b(aaa bbb: String) -&gt; String {
  return bbb
}
let result2 = b(aaa: &quot;aaa&quot;)
print(result) // aaa</code></pre>

<p class="basic-text-box">
  오 함수는 조금 많이 다른 느낌이에요. 
아규먼트를 호출하는 쪽과 동작하는 쪽의 이름을 다르게 쓸 수 있다는 점도 꽤나 매력적인 거 같아요.
</p>
