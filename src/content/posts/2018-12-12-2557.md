<div id="review_text">
<p class="basic-text-box">오늘은 Node의 Koa 프레임워크를 이용하여 아주아주 간단하게 스테틱(정적) 서버를 만들고, SPA에서 만들어서 사용하는 가상 경로를 위한 처리에 대해 적어보려 합니다.
예제: <a href="https://github.com/falsy/blog-post-example/tree/master/koa-static-server" target="_blank" rel="noopener noreferrer">https://github.com/falsy/blog-post-example/tree/master/koa-static-server</a>
<h3>1. Koa 설치 및 실행</h3>
<p class="basic-text-box">우선은 노드 패키지를 만들고 koa와 koa-static을 설치합니다.</p>

<pre class="legacy-code"><code class="language-default">$ npm init</code></pre>
<pre class="legacy-code"><code class="language-default">$ npm install --save koa koa-static</code></pre>
<p class="basic-text-box">샘플을 위한 디랙토리/파일 구조는 아래와 같습니다.</p>

<pre class="legacy-code"><code class="language-default">/src
  index.html
  style.css
index.js</code></pre>
<p class="basic-text-box">간단하게 static server의 코드를 작성해보면,</p>

<pre class="legacy-code"><code class="language-javascript">const koa = require(&#x27;koa&#x27;);
const serve = require(&#x27;koa-static&#x27;);

const app = new koa();
app.use(serve(__dirname + &#x27;/src&#x27;));

const port = 4321;
const server = app.listen(port);
console.log(&#x27;server start port:&#x27; + port);</code></pre>
<p class="basic-text-box">끝.</p>

<pre class="legacy-code"><code class="language-default">$ node index.js</code></pre>
<p class="basic-text-box">위와 같이 서버를 실행하고 'http://localhost:4321/' 로 접속하면 정적 서버가 만들어진 것을 확인 할 수 있습니다.</p>

<h3>2. 가상 경로 설정</h3>
<p class="basic-text-box">프론트 엔드의 프레임워크를 사용하다보면 프론트에서 가상 경로로 라우트 설정을 해서 사용하는 경우가 많은데요.</p>

<pre class="legacy-code"><code class="language-javascript">import { BrowserRouter as Router, Route, Switch } from &#x27;react-router-dom&#x27;;

...

  &lt;route exact=&quot;&quot; path=&quot;/&quot; component=&quot;{Home}&quot;&gt;&lt;/route&gt;
  &lt;route path=&quot;/lab&quot; component=&quot;{lab}&quot;&gt;&lt;/route&gt;
  &lt;route path=&quot;/board/free&quot; component=&quot;{board}&quot;&gt;&lt;/route&gt;

...</code></pre>
<p class="basic-text-box">리액트를 예로 들면, 'react-router-dom' 라는 모듈을 사용해서 'http://도메인/' 일때는 Home 이라는 컴포넌트를 불러오고 'http://도메인/lab/'은 lab 이라는 컴포넌트를 불러오도록 할 수 있습니다.
그런데 기본적으로 path는 디렉토리 구조를 찾게 되는데요, 그러면 서버에서 http://도메인/에 설정해 놓은 root디렉토리에서 파일 경로로 찾게 된답니다.

<p class="basic-text-box">위의 3번째 예를 보면 root로 설정된 디렉토리부터 board 라는 디렉토리를 찾고 그 안에 free 라는 디렉토리를 찾고 그안에서 index.html을 찾겠죠?? 하지만 위 패스는 프론트에서 가상으로 설정한 경로이기 때문에 별다른 설정이 없다면 '404 Not Found'가 된답니다.</p>
<p class="basic-text-box">그렇기에 서버에서는 어떤 Path로 접근하더라도 root 디렉토리의 index.html 파일을 불러오도록 설정해줘야 합니다. 그러면 URL의 Path를 유지하면서 index.html을 불러오고 index.html에서는 프론트의 프레임워크 js파일을 불러오고 Path를 확인해서 해당 Path의 페이지를 그리게 되는 것이지요~</p>
<p class="basic-text-box">해당 설정을 위해 koa-send 모듈을 설치해줍니다.</p>

<pre class="legacy-code"><code class="language-default">$ npm install --save koa-send</code></pre>
<p class="basic-text-box">그리고 index.js에서 코드를 작성합니다.</p>

<pre class="legacy-code"><code class="language-javascript">const koa = require(&#x27;koa&#x27;);
const serve = require(&#x27;koa-static&#x27;);
const send = require(&#x27;koa-send&#x27;);

const app = new koa();
app.use(serve(__dirname + &#x27;/src&#x27;));
app.use(async (ctx) =&gt; {
  if(ctx.status === 404) await send(ctx, &#x27;index.html&#x27;, { root: __dirname + &#x27;/src&#x27; });
});

const port = 4321;
const server = app.listen(port);
console.log(&#x27;server start port:&#x27; + port);</code></pre>
<p class="basic-text-box">이렇게 설정해주면 모든 요청에서 URL Path는 유지하면서 404에서 'root'에서 설정한 디렉토리에서 index.html 을 불러옵니다.</p>
<p class="left-line-box">async, await을 사용해서 Node는 v7.6+ 버전을 사용해야 합니다.</p>
