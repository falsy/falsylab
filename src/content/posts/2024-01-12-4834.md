        </p>
<p class="basic-text-box">
          그래서 사이드바의 활성화 여부를 알 수 있는 방법을 고민하다 알아낸 방법을 적어보려 합니다.
</p>

        <h3>1. GeometryReader를 사용한 사이드바 활성화 여부 확인</h3>

        <pre class="legacy-code"><code class="language-swift">import SwiftUI

struct ContentView: View {
  @State private var isSidebar: Bool = false

  var body: some View {
    GeometryReader { geometry in
      NavigationSplitView {
        Text(&quot;Sidebar&quot;)
      } detail: {
        GeometryReader { innerGeometry in
          Text(&quot;isSidebar: \(String(isSidebar))&quot;)
            .padding()
            .onChange(of: innerGeometry.size) { oldValue, newValue in
              isSidebar = geometry.size.width - innerGeometry.size.width &gt; 0
            }
        }
      }
    }
  }
}

#Preview {
    ContentView()
}</code></pre>

        <p class="basic-text-box">
          짜잔! 아주 간단한 코드인데요.
        </p>

        <p class="basic-text-box">
          GeometryReader 라는 크기를 알려주는 컨테이너 뷰를 사용해서, 전체 너비와 컨텐츠 영역의 너비를 비교하면 이렇게 현재 사이드바의 활성화 상태를 알 수 있답니다.
        </p>
