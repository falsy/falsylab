아주아주 오랜만의 포스팅!</p>
<p class="basic-text-box">
  오늘은 AWS의 DocumentDB를 EC2에 연결해서 외부에서 접속하는 방법에 대해 적어보려 합니다.
사실 이미 AWS에 잘 작성되어 있습니다..</p>
<p class="basic-text-box">
* AWS DocumentDB - EC2 연결:
<a href="https://docs.aws.amazon.com/ko_kr/documentdb/latest/developerguide/connect-ec2.html" target="_blank" rel="noopener noreferrer">https://docs.aws.amazon.com/ko_kr/documentdb/latest/developerguide/connect-ec2.html</a>
* Studio 3T 연결:
<a href="https://docs.aws.amazon.com/ko_kr/documentdb/latest/developerguide/studio3t.html" target="_blank" rel="noopener noreferrer">https://docs.aws.amazon.com/ko_kr/documentdb/latest/developerguide/studio3t.html</a></p>
<p class="left-line-box">
  AWS의 글과 너무 똑같은 내용이라 별 의미가 없을 것 같지만, (아마도) 다른 내용으로 이어서 포스팅을 작성하게 될 것 같아서 우선 가볍게 1편으로 작성해보려 합니다.</p>

<h3>0. 시작하기 전에</h3>
<p class="basic-text-box">
  크게 진행 순서는
1. EC2 보안그룹 만들기
2. EC2 만들기
3. DocumentDB 보안그룹 만들기
4. DocumentDB 만들기
5. EC2 - DocumentDB 연결하기
6. Studio 3T로 연결하기</p>
<p class="left-line-box">
그런데 여기에서, 저는 이미 EC2를 사용하고 있어서 EC2를 따로 만들지 않고 EC2의 보안그룹도 그냥 그대로 사용할 예정입니다.</p>
<p class="left-line-box">
그리고 따로 언급하지 않았는데, 아래 내용은 모두 기본 VPC를 동일하게 사용하고 있습니다.</p>

<h3>1. EC2 보안그룹 만들기</h3>
<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/11.png" alt=""></figure>
<p class="basic-text-box">
  AWS 에서 EC2 서비스로 이동해서 보안그룹 -&gt; 보안그룹 생성을 누릅니다.
그리고 이름과 설명을 입력한 후 인바운드를 설정해 줍니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/22.png" alt=""></figure>
<p class="left-line-box">
  이건 지금 제가 사용하고 있는 EC2의 보안그룹인데요. 옛날에 무지성으로 만들어서 보안그룹 이름도 디폴트 이름이고 http, https, ssh에 모든 ip를 허용해두었네요.
현재 블로그로 사용하고 있는 EC2라서 http, https 는 모두 열어두더라도 ssh는 제가 사용하는 ip로 제한해두는 편이 좋겠네요.</p>
<p class="basic-text-box">
일단, 이번에 새로 보안그룹을 만드셨다면.
ssh로 자신의 ip를 통해 접근할 수 있도록 인바운드 규칙에 추가해주세요.
(이따가 ssh로 EC2에 접속해서 DocumentDB에 액세스 할 예정이에요.)</p>

<h3>2. EC2 만들기</h3>
<p class="basic-text-box">
저는 기존의 사용하고 있던 EC2를 사용하고,
EC2를 만드는 방법은 이번 포스팅 논지에 좀 벗어나는 것 같아서 생략할게요.
(저는 Ubuntu 18.04.2 LTS 버전을 사용하고 있습니다.)</p>

<h3>3. DocumentDB 보안그룹 만들기</h3>
<p class="basic-text-box">
  1번과 동일하게 보안그룹 생성 버턴을 누릅니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/333.png" alt=""></figure>
<p class="basic-text-box">
  보안그룹의 이름과 설명을 적어주고, 인바운드 규칙에 '사용자 지정 TCP' 그리포 포트번호는 '27017' 그리고 소스는 아까 1번에서 만들었던 EC2의 보안그룹을 설정한 후에 생성해줍니다.</p>
<p class="left-line-box">
  약간의 설명을 더하자면, DocumentDB는 Amazon VPC 내에서 배포되어 EC2나 또는 동일한 VPC에 배포된 AWS의 서비스를 통해서만 직접 액세스 할 수 있습니다.
그래서 보안그룹에 동일한 VPC에 있는 EC2에 인바운드를 추가해서 외부에서 EC2를 통해서 DocumentDB에 액세스 합니다.</p>

<h3>4. DocumentDB 만들기</h3>
<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/44.png" alt=""></figure>
<p class="basic-text-box">
  Amazon DocumentDB 서비스로 이동해서 클러스트에서 생성 버튼을 누릅니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/55.png" alt=""></figure>

<p class="left-line-box">
  저는 포스팅을 하고 바로 지울거라 가장 저렴한 인스턴스 클래스와 개수는 1개로 하였습니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/66.png" alt=""></figure>

  그리고 아래의 '고급 설정 표시'를 활성화 한 후 3번에서 만들었던 보안그룹을 설정해 줍니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/77.png" alt=""></figure>

<h3>5. EC2 - DocumentDB 연결하기</h3>
<p class="basic-text-box">
  이제 EC2에 가서 DocumentDB에 접속해볼까요? 우선 ssh로 EC2에 접속합니다.</p>

<pre class="legacy-code"><code class="language-text">$ ssh -i &quot;falsyxxxx.pem&quot; ubuntu@ec2-12-345-678-910.ap-northeast-2.compute.amazonaws.com</code></pre>
<p class="left-line-box">
  여기 부분은 AWS 가이드 문서와 완전 동일합니다.
저는 ubuntu 18.04 버전을 사용하고 있습니다.</p>
<p class="basic-text-box">
  1. 패키지 관리 시스템에서 사용할 퍼블릭 키를 가져옵니다.</p>

<pre class="legacy-code"><code class="language-text">  sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv 2930ADAE8CAF5059EE73BB4B58712A2291FA4AD5 </code></pre>
<p class="basic-text-box">
  2. Ubuntu 버전에 맞는 명령을 사용하여 MongoDB의 목록 파일 /etc/apt/sources.list.d/mongodb-org-3.6.list를 생성합니다.</p>

<pre class="legacy-code"><code class="language-text">  echo &quot;deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu xenial/mongodb-org/3.6 multiverse&quot; | sudo tee /etc/apt/sources.list.d/mongodb-org-3.6.list</code></pre>
<p class="basic-text-box">
  3. 다음 명령을 사용하여 로컬 패키지 데이터베이스를 다시 로드합니다.</p>

<pre class="legacy-code"><code class="language-text">  sudo apt-get update</code></pre>
<p class="basic-text-box">
  4. MongoDB 셸을 설치합니다.</p>

<pre class="legacy-code"><code class="language-text">  sudo apt-get install -y mongodb-org-shell</code></pre>
<p class="basic-text-box">
  설치가 끝나면 DocumentDB의 클러스트 탭으로 이동해서 생성한 클러스터를 선택합니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/88.png" alt=""></figure>
<p class="basic-text-box">
  이제 저 페이지에 '연결'에 보이는 것처럼 EC2의 ssh에 입력해주시면 되는데요.
우선 현재 인증기관 인증서가 없으니까 우선 인증서를 다운로드 해줍니다.</p>
<p class="left-line-box">
 EC2에 ssh로 접속한 상태로 아래 명령어를 통해 Ubuntu에 인증서를 다운로드해 주는 거에요.</p>

<pre class="legacy-code"><code class="language-text">  wget https://s3.amazonaws.com/rds-downloads/rds-combined-ca-bundle.pem</code></pre>
<p class="basic-text-box">
  설치 후 ls 명령어를 입력해보시면 rds-combined-ca-bundle.pem 파일이 추가된 걸 확인 하실 수 있습니다.</p>
<p class="basic-text-box">
  그리고 아래에 적힌('mongo --ssl ...') 명령어를 입력해주시면 접속이 된답니다.</p>

<pre class="legacy-code"><code class="language-text">  mongo --ssl --host docdb-test-falsy.cluster-cavb6csgrp65.ap-northeast-2.docdb.amazonaws.com:27017 --sslCAFile rds-combined-ca-bundle.pem --username falsy --password &lt;암호삽입&gt;</code></pre>
<figure><img style="max-width: 100%;" src="/wp-content/uploads/2021/06/99.png" alt=""></figure>
<p class="basic-text-box">
  짜잔</p>
