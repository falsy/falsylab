<h3>1. 보안 그룹 만들기</h3>
<p class="basic-text-box">
  시작은 보안 그룹! 우선 앞서 이야기한 대로 ELB와 Lambda를 사용할 거니까 두 개의 보안 그룹을 만들 거에요. 간단하게 만들 거라 SSL은 쓰지 않을 거니까 ELB의 보안 그룹은 모든 외부 HTTP 통신 접근을 허용하는 보안 그룹을 만들고, 해당 ELB 보안 그룹에서만 인바운드 할 수 있는 Lambda 보안 그룹을 만들 거랍니다.</p>
<img src="/wp-content/uploads/2020/06/1.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  보안 그룹은 EC2 서비스에 있고, 왼쪽 메뉴 중(1번) '보안 그룹'을 선택한 후 오른쪽 위쪽의(2번) '보안 그룹 생성' 버튼을 눌러서 생성합니다.</p>
<img src="/wp-content/uploads/2020/06/2.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  위 이미지처럼 보안 그룹의 이름을 정해주고 인바운드 규칙을 모든 위치의 HTTP 연결을 허용해 주고 아래의 '보안 그룹 생성' 버튼을 눌러줍니다! 그리고 이번엔 Lambda에서 사용할 보안 그룹도 만들어 줄게요.</p>
<img src="/wp-content/uploads/2020/06/3.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  아까 만들었던 것처럼 보안 그룹 이름을 정해주고 이번엔 인바운드로 조금 전에 만든 'test-elb'라는 보안 그룹을 허용해 주고 '보안 그룹 생성' 버튼을 눌러 생성해 줍니다.</p>

<h3>2. Koa API 서버 만들기</h3>
<p class="basic-text-box">
  엄청청 간단하게 Koa 서버를 만들어 볼게요.</p>

<pre class="legacy-code"><code class="language-javascript">const Koa = require(&quot;koa&quot;);
const Router = require(&quot;koa-router&quot;);
const cors = require(&#x27;@koa/cors&#x27;);
const router = new Router();

const app = new Koa();
app.use(cors());

router.get(&#x27;/test1&#x27;, (ctx) =&gt; {
  ctx.body = &#x27;hello&#x27;;
});

router.get(&#x27;/test2&#x27;, (ctx) =&gt; {
  ctx.body = &#x27;world&#x27;;
});

app.use(router.routes());

app.listen(4000, () =&gt; {
  console.log(`Server is running on port 4000!`);
});</code></pre>
<p class="basic-text-box">
  하지만 우리는 Lambda에서 함수로 사용해야 하니까 그냥 이렇게 Lambda에 배포하면 안 돼요.</p>
<p class="left-line-box">
  직접 해보진 않았지만.. 의식의 흐름대로 생각해보면 이대로 Lambda에 올리게 되면,
가령 'domain.com/test1' 라는 요청을 왔을 때
Lambda는 서버를 열고 아무것도 응답해 주지 않으니 404를 응답하게 되지 않을까요??</p>
<p class="basic-text-box">
  그래서 우리는 이제 Node의 프레임워크인 Serverless의 플러그인인 Serverless HTTP를 사용해서 수정해 줄 거예요. Serverless HTTP 플러그인은 아주 간단해요. 공홈 적혀있는 간단한 예를 적어보자면,</p>

<pre class="legacy-code"><code class="language-javascript">const serverless = require(&#x27;serverless-http&#x27;);
const Koa = require(&#x27;koa&#x27;); // or any supported framework

const app = new Koa();

app.use(/* register your middleware as normal */);

// this is it!
module.exports.handler = serverless(app);

// or as a promise
const handler = serverless(app);
module.exports.handler = async (event, context) =&gt; {
  // you can do other things here
  const result = await handler(event, context);
  // and here
  return result;
};</code></pre>
<p class="basic-text-box">
  이제 위 예를 참고해서 코드를 수정해 줄 거예요.</p>

<pre class="legacy-code"><code class="language-javascript">const serverless = require(&#x27;serverless-http&#x27;);
const Koa = require(&quot;koa&quot;);
const Router = require(&quot;koa-router&quot;);

router.get(&#x27;/test2&#x27;, (ctx) =&gt; {
  ctx.body = &#x27;world&#x27;;

app.use(router.routes());

module.exports.handler = serverless(app);</code></pre>

<h3>4. 로드밸런서(ELB) 만들기</h3>
<p class="basic-text-box">
  이제 거의 다 왔답니다! 마지막 로드밸런서 만들기!
AWS의 EC2 서비스로 이동해서 왼쪽 메뉴의 로드밸런서를 선택한 후 '로드 밸런서 생성' 버튼을 선택합니다.</p>
<img src="/wp-content/uploads/2020/06/7.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  유형으로는 Application Load Balancer (HTTP / HTTPS)를 선택할 거예요.</p>
<img src="/wp-content/uploads/2020/06/8.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  로드 밸런서의 이름을 정해주고, 가용 영역의 VPC와 서브넷은 기본 값으로 설정한 후 '다음: 보안 설정 구성' 버튼을 선택해 줍니다.</p>
<p class="left-line-box">
  이쯤 되면 VPC와 서브넷에 대해서 이야기를 해야 할 것만 같지만, 이 부분은 다음 기회에...</p>
<p class="basic-text-box">
  HTTPS를 사용하라는 안내 문구는 살포시 넘기고,
(만약 실제 서비스라면 요즘은 HTTPS는 기본적으로 사용하는 게 좋겠죠? AWS에서는 ACM(AWS Certificate Manager)에서 SSL인승서를 편하게 발급받아 사용할 수 있답니다. 이 부분도 다음에 기회가 된다면..)</p>
<p class="basic-text-box">
  다음 보안 그룹은, 역시 아까 처음에 만들었던 'test-elb'라는 보안 그룹을 선택해 줍니다.</p>
<img src="/wp-content/uploads/2020/06/9.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  그리고 로드벨런서의 대상 그룹을 만들어 줍니다, 대상 유형은 Lambda 함수로 설정할게요.
음... 그러니까, ELB - Lambda 또는 ELB - EC2 이런 식으로 바로 연결되는 게 아니고 중간에 대상 그룹을 설정해서 ELB - 대상 그룹 - Lambda 또는 ELB - 대상 그룹 - EC2 이렇게 되어 있어서, 언제든 대상 그룹을 통해서 ELB의 대상 값을 변경할 수 있답니다.</p>
<p class="left-line-box">
  이런 부분들이 OOP 적이면서 또, MSA의 강점이겠죠?</p>
<img src="/wp-content/uploads/2020/06/10.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  대상으로 아까 만들었던 Lambda 함수를 설정해 주면 끝!</p>
<img src="/wp-content/uploads/2020/06/11.png" alt="" style="max-width: 100%;">
<p class="basic-text-box">
  'test-api-server-lb' 라는 로드 밸런서가 만들어졌고 현재 'provisioning' 상태네요. 그리고 DNS 이름은 A 레코드로 'test-api-server-lb-336024832.ap-northeast-2.elb.amazonaws.com'라고 만들어졌네요.</p>
<p class="basic-text-box">
  이제 조금 기다리면 상태 값이 'active'로 변경될 거예요.</p>

<h3>5. 테스트</h3>
<p class="basic-text-box">
  방금 만든 로드 밸런서가 active 상태가 되면 로드 밸런서가 우리가 만든 koa - serverless http로 구성된 Lambda 함수를 잘 호출하는지 테스트해볼가요?
앞서 발급받은 DNS URL을 브라우저에서 붙여넣기 하거나 터미널에서 cURL로 확인합니다.</p>

<pre class="legacy-code"><code class="language-default">$ curl test-api-server-lb-336024832.ap-northeast-2.elb.amazonaws.com/test1
# hello
$ curl test-api-server-lb-336024832.ap-northeast-2.elb.amazonaws.com/test2
# world</code></pre>
