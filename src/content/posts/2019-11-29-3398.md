<p style="margin-bottom: 30px;">
다음의 포스팅은 OOP나 클린 아키텍처가 될 줄 알았으나...
오늘은 CI/CD 플랫폼인 Github Actions를 아주 아주 간단한, 맛보기 글을 적어보려 합니다.
(아주 자세히, 그리고 구체적으로 적고 싶지만, 사실 저도 오늘 처음...)</p>
<p class="left-line-box">
  이 글의 예제 코드는 깃허브 저장소에 올려놓았습니다~
<a href="https://github.com/falsy/blog-post-example/tree/master/github-actions-quickstart-1" target="_blank" rel="noopener noreferrer">https://github.com/falsy/blog-post-example/tree/master/github-actions-quickstart-1</a></p>

<h3>1. 무작정 시작하기</h3>
<p class="basic-text-box">
  어느날인가 깃허브에 새로운 Actions 라는 탭이 추가되었습니다. 뚜둔!
(한참 전부터 Beta로 이미 서비스되고 있었다는 것을 몰랐다는 사실은 안 비밀..)</p>
<figure><img src="/wp-content/uploads/2019/11/github-actions-1-scaled.png" alt="" style="max-width: 100%;"></figure>
<p class="basic-text-box">
  일단은 깃허브에 레파지토리를 하나 만들어 보았습니다. 그리고 과감하게 'Actions' 탭 클릭!</p>
<figure><img src="/wp-content/uploads/2019/11/github-actions-2-1.png" alt="" style="max-width: 100%;"></figure>
<p class="basic-text-box">
  그리고 저는 가장 친숙하게 보이는 Node를 선택하였습니다.
아래의 문구를 보니 대충 npm build를 하고 npm test를 실행하는 샘플코드 인가봐요.</p>
<figure><img src="/wp-content/uploads/2019/11/github-actions-3.png" alt="" style="max-width: 100%;"></figure>

<pre class="legacy-code"><code class="language-text">name: Node CI

on: [push]

jobs:
  build:

    runs-on: ubuntu-latest

    strategy:
      matrix:
        node-version: [8.x, 10.x, 12.x]

    steps:
    - uses: actions/checkout@v1
    - name: Use Node.js ${{ matrix.node-version }}
      uses: actions/setup-node@v1
      with:
        node-version: ${{ matrix.node-version }}
    - name: npm install, build, and test
      run: |
        npm ci
        npm run build --if-present
        npm test
      env:
        CI: true</code></pre>
<p class="basic-text-box">
  굉장히 익숙하지 않은 YAML 코드이지만, 대충 보았을때, on에 push가 있는 것으로 보아 레파지토리에 푸시될때 실행이 되고 OS는 최신의 Ubuntu가 켜지고 node-verions 8, 10, 12 버전에서 코드를 실행하려나 봅니다.</p>
<p class="basic-text-box">
그리고 actions/checkout@v1, actions/setup-node@v1 이건 따로 정의한 적이 없는데 있는 것으로 보아 깃헙에서 기본적으로 내장되어 있는 액션이 아닐까 싶어요.
아마도 이름처럼 체크아웃하고 노드를 설치하겠죠?</p>
<p class="basic-text-box">
그리고 run. 설치된 노드에서 수행하는 명령어를 입력하는 란인가 봐요.
npm ci, npm build, npm test 를 수행하고 끝나려나 봅니다.</p>
<p class="basic-text-box">
  역시 과감하게 'Start commit' 버튼을 클릭!</p>
<figure><img src="/wp-content/uploads/2019/11/github-actions-4-scaled.png" alt="" style="max-width: 100%;"></figure>
<p class="basic-text-box">
  이렇게 새로운 파일들이 추가된걸 확인 할 수 있습니다.</p>
<figure><img src="/wp-content/uploads/2019/11/github-actions-5-scaled.png" alt="" style="max-width: 100%;"></figure>
<p class="basic-text-box">
  다시 'Actions' 탭으로 이동해서 좀 전에 자동으로 만들어준 'Node CI'를 눌러서 확인해보면 위와 같이 npm install, build, and test 단계에서 실패한걸 확인 할 수 있습니다.
그렇죠. 빈 레파지토리이다 보니...
그러면 정말로 CI가 정상적으로 잘 동작하는지 한번 샘플 코드를 작성해서 커밋, 푸시 해보겠습니다.</p>

<h3>2. 샘플 코드 작성</h3>
<p class="basic-text-box">
  새로 만든 레파지토리를 clone 받은 후 npm init을 하고 제가 주로 사용하는 Webpack과 Babel을 설치하고 간단하게 Mocha로 테스트 코드를 작성해보겠습니다.</p>

<pre class="legacy-code"><code class="language-text">$ npm install --save-dev @babel/core @babel/preset-env @babel/register babel-loader html-loader html-webpack-plugin webpack webpack-cli webpack-dev-server mocha</code></pre>
<p class="basic-text-box">우선 필요한 패키지들을 설치해 줍니다. Babel, Webpack, Mocha..</p>

<pre class="legacy-code"><code class="language-javascript">// package.json

<p class="basic-text-box">
  그리고 위와 같이 간단하게 webpack.config.js 파일을 작성합니다.</p>

<pre class="legacy-code"><code class="language-javascript">// src/service/functions.js
export const toUpperCase = text =&gt; text.toUpperCase();</code></pre>
<p class="basic-text-box">
테스트 할 샘플 스크립트를 하나 만들고</p>

<pre class="legacy-code"><code class="language-javascript">// test/functions.spec.js
const assert = require(&#x27;assert&#x27;);
const { toUpperCase } = require(&#x27;../src/service/functions&#x27;);

describe(&#x27;Github Actions Test&#x27;, () =&gt; {
  it(&#x27;toUpperCase&#x27;, () =&gt; {
    const textText = &#x27;hello world&#x27;;
    assert.equal(toUpperCase(textText), &#x27;HELLO WORLD&#x27;);
  });
});</code></pre>
<p class="left-line-box">그 밖의 코드는 깃허브 레파지토리에서 확인하실 수 있습니다.
<a href="https://github.com/falsy/blog-post-example/tree/master/github-actions-quickstart-1" target="_blank" rel="noopener noreferrer">https://github.com/falsy/blog-post-example/tree/master/github-actions-quickstart-1</a></p>
<p class="basic-text-box">
  test 폴더에 테스트 스펙도 작성해 주고 레파지토리에 푸시해 줍니다.
그러면 아까 샘플로 작성해두었던 'Node CI'가 on [push] 에서 실행하도록 했으니까 'Actions'탭의 'Node CI'가 진행이 된답니다.</p>
<figure><img src="/wp-content/uploads/2019/11/github-actions-6-scaled.png" alt="" style="max-width: 100%;"></figure>
