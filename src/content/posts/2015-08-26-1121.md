<h3 style="border-top:0;">Chapter.4 터미널로 깃 사용하기</h3>
<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_3_1.jpg" alt="git_3_1" width="700" height="392" class="alignnone size-full wp-image-1147"></p>
<p style="padding-left:20px;">우선 다시 github 사이트로 돌아와 clone URL를 복사합니다.</p>
<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_3_2.jpg" alt="git_3_2" width="700" height="319" class="alignnone size-full wp-image-1149"></p>
<p style="padding-left:20px;">저는 'documents' 에 'git' 이라는 폴더를 미리 만들어 놓은 후 터미널을 열었습니다.
1. cd /Users/Cheolguso/Documents/git [해당 디렉토리로 이동한 후]
2. git clone [위에서 복사한 URL] (ex. git clone https://github.com/CheolJeJo/new-repository-name.git)
[ &#x2663; 여기서 clone은 깃허브 저장소의 내용을 복재하여 로컬에 저장합니다. ]
<h3 style="border-top:0;">Chapter.5 파일 수정하기</h3>
<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_4_1.jpg" alt="git_4_1" width="700" height="319" class="alignnone size-full wp-image-1152"></p>
<p style="padding-left:20px;">readme.md 파일에 접근하여 "See you"라는 텍스트를 추가하겠습니다.
1. cd [프로젝트 이름(저장소 이름)] (ex. cd  new-repository-name)
2. vi readme.md [vi 모드로 파일 수정]

<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_4_2.jpg" alt="git_4_2" width="700" height="319" class="alignnone size-full wp-image-1157"></p>
<p style="padding-left:20px;">
1. 'i' 를 누르면 인설트 모드로 변경됩니다.
2. "See you" 텍스트 타이핑
3. 'esc'를 눌러서 인설트 모드 종료
4. ':' 를 눌러 명령어 창을 띄우고
5. 'wq!' 저장하고 끝내기 ('!'표는 실행을 묻지 않음)

<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_4_3.jpg" alt="git_4_3" width="700" height="319" class="alignnone size-full wp-image-1163"></p>
<p style="padding-left:20px;">변경한 사항을 전송하기에 앞 서
1. git config --global user.name "your name" [깃허브 계정 이름을 설정해 줍니다.]
(ex. git config --global user.name "CheolJeJo")
2. git config --global user.email "your mail" [깃허브 계정의 이메일을 설정해 줍니다.]
(ex. git config --global user.email "mail@cheolguso.com")
[ &#x2663; git config 다음 global앞의 - 는 2개 입니다. ]

<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_4_4.jpg" alt="git_4_4" width="700" height="319" class="alignnone size-full wp-image-1169"></p>
<p style="padding-left:20px;">1. cd ../ [다시 git 디렉토리로 돌아가서]
2. git commit -m  "edit readme.md" /Users/Cheolguso/Documents/git/new-repository-name
["edit readme.md"라는 커밋]

<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_4_5.jpg" alt="git_4_5" width="700" height="319" class="alignnone size-full wp-image-1172"></p>
<p style="padding-left:20px;">1. cd new-repository-name [다시 저장소 디렉토리로 돌아가서]
2. git push origin master [수정된 사항을 깃허브에 푸시(전송?)]

<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_5_1.jpg" alt="git_5_1" width="700" height="376" class="alignnone size-full wp-image-1175"></p>
<p style="padding-left:20px;">깃허브 사이트로 돌아와서 수정된 사항 확인.</p>

<h3 style="border-top:0;">Chapter.6 디렉토리 및 파일 추가하기</h3>
<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_6_1.jpg" alt="git_6_1" width="700" height="319" class="alignnone size-full wp-image-1185"></p>
<p style="padding-left:20px;"> mkdir img [로컬 저장소 디렉토리에 img 폴더를 추가합니다.]</p>
<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_6_2.jpg" alt="git_6_2" width="700" height="319" class="alignnone size-full wp-image-1186"></p>
<p style="padding-left:20px;">img 라는 폴더안에 저는 logo.png 라는 이미지 파일을 추가하였습니다.</p>
<p style="background: #f5f8f6; padding: 15px 20px; margin-bottom:5px;"><img src="/wp-content/uploads/2015/08/git_6_3.jpg" alt="git_6_3" width="700" height="319" class="alignnone size-full wp-image-1191"></p>
<p style="padding-left:20px;">
1. git add ./* [현제 디랙토리 이후의 모든 파일을 추가합니다]
2. git commit -m "add images" /Users/Cheolguso/Documents/git/new-repository-name ["add images" 라는 커밋]
3. git push origin master [수정된 사항을 푸시]

<p style="padding-left:20px;">깃허브 사이트로 돌아와 수정된 사항 확인</p>
