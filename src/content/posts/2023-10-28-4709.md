<h3>1. React</h3>
<p class="basic-text-box">
  우선 필요한 패키지를 설치해 줍니다.</p>

<pre class="legacy-code"><code class="language-javascript">$ npm i -D i18next react-i18next</code></pre>
<p class="basic-text-box">
  다음으로 간단하게 한국어과 영어로 언어셋을 만들어 줄게요.</p>

<pre class="legacy-code"><code class="language-javascript">// src/locales/ko.json

}</code></pre>
<pre class="legacy-code"><code class="language-javascript">// src/localse/en.json
{
  &quot;안녕하세요&quot;: &quot;hello&quot;
}</code></pre>
<p class="basic-text-box">
    다음으로 i18n 설정도 간단하게,</p>

<pre class="legacy-code"><code class="language-javascript">// src/localse/i18n.ts

<p class="basic-text-box">
  그럼 이제 설정한걸 적용해 볼까요?</p>

<pre class="legacy-code"><code class="language-javascript">// src/index.tsx

<h3>3. Next (App Directory)</h3>
<p class="basic-text-box">
  작성하는 김에, 마지막으로! Next의 앱 디랙토리 구조에서의 적용도 해볼게요.</p>
<p class="basic-text-box">
  우선 i8n 설정을 먼저 해줄게요.
아까와 같이 언어셋을 app 디랙토리 안에 i18n 폴더를 만들고 그안에 위치해줄게요.</p>

<pre class="legacy-code"><code class="language-javascript">// app/i18n/locales/ko/common.json
{
  &quot;안녕하세요&quot;: &quot;안녕하세요&quot;
}</code></pre>
<pre class="legacy-code"><code class="language-javascript">// app/i18n/localse/en/common.json
{
  &quot;안녕하세요&quot;: &quot;hello&quot;
}</code></pre>
<p class="basic-text-box">
  그리고 설정파일을 만들어줄게요.</p>

<pre class="legacy-code"><code class="language-javascript">// app/i18n/settings.ts
export const fallbackLng = &#x27;ko&#x27;
export const languages = [fallbackLng, &#x27;en&#x27;]
export const defaultNS = &#x27;common&#x27;

export function getOptions (lng = fallbackLng, ns = defaultNS) {
  return {
    supportedLngs: languages,
    fallbackLng,
    lng,
    fallbackNS: defaultNS,
    defaultNS,
    ns,
  }
}</code></pre>
<p class="basic-text-box">
  다음 useTranslation를 만들어 줄게요.</p>

<pre class="legacy-code"><code class="language-javascript">// app/i18n/index.ts
import { createInstance } from &#x27;i18next&#x27;
import resourcesToBackend from &#x27;i18next-resources-to-backend&#x27;
import { initReactI18next } from &#x27;react-i18next/initReactI18next&#x27;
import { getOptions } from &#x27;./settings&#x27;

const initI18next = async (lng: string, ns?: string) =&gt; {
  const i18nInstance = createInstance()
  await i18nInstance
    .use(initReactI18next)
    .use(resourcesToBackend((language: string, namespace: string) =&gt; import(`./locales/${language}/${namespace}.json`)))
    .init(getOptions(lng, ns))
  return i18nInstance
}

export async function useTranslation(lng: string, ns?: string, options: any = {}) {
  const i18nextInstance = await initI18next(lng, ns)
  return {
    t: i18nextInstance.getFixedT(lng, Array.isArray(ns) ? ns[0] : ns, options.keyPrefix),
    i18n: i18nextInstance
  }
}</code></pre>
<p class="basic-text-box">

<pre class="legacy-code"><code class="language-javascript">// app/[lng]/page.ts
&#x27;use client&#x27;

import { fallbackLng, languages } from &#x27;../i18n/settings&#x27;
import { useTranslation } from &#x27;../i18n&#x27;

<p class="basic-text-box">
  그런데 이렇게 되면, / 패스로 접근하게 되면 404가 뜨기 때문에 middleware를 만들어 줍니다.</p>

<pre class="legacy-code"><code class="language-javascript">// middleware.ts
import { NextRequest, NextResponse } from &#x27;next/server&#x27;
import { fallbackLng, languages } from &#x27;./app/i18n/settings&#x27;

export const config = {
  matcher: [&#x27;/((?!api|_next/static|_next/image|assets|favicon.ico|sw.js).*)&#x27;]
}

export function middleware(req: NextRequest) {
  if (!languages.some(loc =&gt; req.nextUrl.pathname.startsWith(`/${loc}`))) {
    return NextResponse.redirect(new URL(`/${fallbackLng}${req.nextUrl.pathname}`, req.url))
  }

  return NextResponse.next()
}</code></pre>
<p class="basic-text-box">
  조건문 그대로 URI의 패스가 제가 등록한 언어 이름으로 시작하지 않으면 fallbackLng으로 리다이렉트 시키도록 합니다. 위에 config는, 미들웨어가 실행되는 매칭 기준?? 을 설정하는 거에요.
(api, static, image, assets, favicon, sw이 호출 될때는 아래 미들웨어가 실행되지 않도록)</p>
