<h3>1. Custom Actions 레파지토리 만들기</h3>
<p class="basic-text-box">
  저는 'github-custom-actions' 라는 이름으로 Github에 레파지토리를 만들었어요.
그리고 그 안에는 아래와 같이 간단한 3개의 파일로 되어 있습니다.</p>

<pre class="legacy-code"><code class="language-text">github-custom-actions
  Dockerfile
  entrypoint.sh
  action.yml</code></pre>
<pre class="legacy-code"><code class="language-text"># /Dockerfile
FROM ubuntu:18.04
# 18.04 버전의 Ubuntu OS를 띄우고

ADD entrypoint.sh /entrypoint.sh
# entrypoint.sh 파일을 추가하고

RUN chmod +x /entrypoint.sh
# entrypoint.sh 파일에 권한을 주고

ENTRYPOINT [&quot;/entrypoint.sh&quot;]
# entrypoint.sh 를 수행합니다.</code></pre>
<p class="left-line-box">
  여기서 잠시 Dockerfile에서 ENTRYPOINT와 CMD의 차이를 알아두고 넘어가면 좋을 거 같아요.
아주 간단하게 이야기하면 CMD는 이후 컨테이너를 실행할때 인자값을 주었을때 변경되어 실행될 수 있고
ENTRYPOINT는 Dockerfile에서 지정한 명령만 수행한답니다.
참고. <a href="https://bluese05.tistory.com/77" target="_blank" rel="noopener noreferrer">https://bluese05.tistory.com/77</a></p>

<pre class="legacy-code"><code class="language-text"># /entrypoint.sh
#!/bin/sh
# 위에는 주석이 아니에요.

echo &quot;Hello World&quot;
# Hello World 를 출력</code></pre>
<p class="left-line-box">
  저와 같이 쉘스크립트가 익숙하지 않으시다면, '#!/bin/sh' 부분은 아래의 링크를 참고하시면 좋을 거 같습니다.
참고. <a href="https://storycompiler.tistory.com/101" target="_blank" rel="noopener noreferrer">https://storycompiler.tistory.com/101</a></p>

<pre class="legacy-code"><code class="language-text"># /action.yml
name: &#x27;hello world&#x27;
description: &#x27;add actions&#x27;
runs:
  using: &#x27;docker&#x27;
  image: Dockerfile</code></pre>
<p class="basic-text-box">
  위와 같이 3개의 파일로 된 액션 레파지토리를 만들었습니다.</p>

<h3>2. Custom Actions 사용하기</h3>
<p class="basic-text-box">
  이제 앞에 만든 Custom Actions을 사용해보기 위해 저는 'github-actions-quickstart-2'라는 레파지토리를 하나 만들었어요.
대충 전체적으로 코드는 저번 글의 'github-actions-quickstart-1'와 똑같고 .github/workflows/nodjs.yml 파일만 수정해봤어요.</p>

<pre class="legacy-code"><code class="language-text"># /.github/workflows/nodjs.yml
name: Node CI

on: [push]

jobs:
  build:

    runs-on: ubuntu-latest

    steps:
    - name: &#x27;add actions test&#x27;
      uses: falsy/github-custom-actions@master
      id: test</code></pre>
<p class="left-line-box">
  뭔가 저번에 쓰던거 복붙해서 썼더니 nodejs 안쓰는데 이름이 Node CI네요.. (쉿..)</p>
<p class="basic-text-box">
  사실 저번글에서 많이 지워지고, 중요한 부분은 'uses' 부분이겠죠?
앞에 falsy는 제 깃허브 이름이고 뒤에는 조금 전에 만들었던 레파지토리의 이름이에요.</p>
<p class="basic-text-box">
  그리고 Push를 하고 Actions 탭을 확인해 볼까요?</p>
<figure><img src="/wp-content/uploads/2019/12/12.png" alt="" style="max-width: 100%;"></figure>
<p class="basic-text-box">
  짜잔 '잘 보면 Hello World'가 출력된 걸 볼 수 있답니다.</p>

<h3>3. 깃허브 패키지 레지스트리 등록하기 #1 토큰 발급</h3>
<p class="basic-text-box">
  우선은 Docker를 사용해야하니 Docker를 설치되어 있어야 한답니다. 이전에 썼던 도커 설치 글을 참고할 수 있을 거 같아요.
<a href="/docker를-설치하고-간단하게-nginx-node-서버를-배포해봅니다/" target="_blank" rel="noopener noreferrer">/docker를-설치하고-간단하게-nginx-node-서버를-배포해봅니다/</a></p>
<figure><img src="/wp-content/uploads/2019/12/13.png" alt="" style="max-width: 100%;"></figure>
<p class="basic-text-box">
  우선은 깃허브에서 프로필 아이콘을 누르고 'Settings'로 이동합니다.</p>
<figure><img src="/wp-content/uploads/2019/12/14.png" alt="" style="max-width: 100%;"></figure>
<p class="basic-text-box">
  왼쪽 메뉴에서 'Developer settings' 로 이동한 후 'Personal access tokens' 로 가서 'Generate new token'을 눌러 토큰을 만들어 줍니다.
권한으로는 read:packages, repo, write:packages 가 필요하다고 해요.
참고. <a href="https://coffeewhale.com/cicd/github/2019/10/14/github-actions/" target="_blank" rel="noopener noreferrer">https://coffeewhale.com/cicd/github/2019/10/14/github-actions/</a></p>
<p class="basic-text-box">
  token을 만들면 '069606298e62fb...' 대충 이렇게 생긴 값이 생성되는데 요걸을 복사해주세요.</p>

<h3>3. 깃허브 패키지 레지스트리 등록하기 #2 Docker 로그인</h3>
<p class="basic-text-box">
  그리고 터미널을 열고 아까 처음에 만들었던 github-custom-actions 디렉토리로 이동해 줍니다.</p>

<pre class="legacy-code"><code class="language-text">$ cd /Users/falsy/Documents/Project/github-custom-actions</code></pre>
<p class="left-line-box">
  위 경로는 그냥 저의 경로에요..</p>
<p class="basic-text-box">
  그리고 docker 로그인을 합니다.</p>

<pre class="legacy-code"><code class="language-text">$ docker login docker.pkg.github.com --username falsy -p 069606298e62fb...</code></pre>
<p class="left-line-box">
  여기에서 'falsy' 부분에 사용하시는 github 이름을 그리고 -p 다음에 아까 만들었던 token을 넣어주면 되요.</p>

<h3>3. 깃허브 패키지 레지스트리 등록하기 #2 Docker 빌드 및 배포</h3>
<pre class="legacy-code"><code class="language-text">$ docker build -t docker.pkg.github.com/false/github-custom-actions/test:1.0 .</code></pre>
<p class="basic-text-box">
  빌드하여 이미지를 만듭니다. 위에 -t 다음은 태그 이름이고 맨 뒤에 .은 디렉토리 패스 값이에요.</p>

<pre class="legacy-code"><code class="language-text">$ docker tag docker.pkg.github.com/falsy/github-custom-actions/test:1.0</code></pre>
<p class="basic-text-box">
  빌드한 이미지에 태그를 등록하고</p>

<pre class="legacy-code"><code class="language-text">$ docker push docker.pkg.github.com/falsy/github-custom-actions/test:1.0</code></pre>
<p class="basic-text-box">
  이제 푸시하면 끝~</p>
