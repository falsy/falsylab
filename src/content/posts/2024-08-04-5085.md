<h3>2. 학습 코드 만들기</h3>

<p class="basic-text-box">
  앞서 이야기한대로 TensorFlow와 Keras를 사용해서 학습 코드를 만들어 줄 건데요.
  우선 필요한 패키지를 먼저 정의하고 설치해 줍니다.
</p>

<p class="left-line-box">
  개발 환경은 macOS이고 Python은 v3.9.7 를 사용하고 있습니다.
</p>

<pre class="legacy-code"><code class="language-bash">// requirements.txt
flask
tensorflow
pillow
scipy
matplotlib</code></pre>

<p class="basic-text-box">
  가상 환경을 만들고 활성화해주고, 패키지를 설치해 줍니다.
</p>

<pre class="legacy-code"><code class="language-bash">$ python3 -m venv .venv
$ source .venv/bin/activate</code></pre>

<p class="left-line-box">
  가상환경은 'deactivate' 명령어로 종료할 수 있습니다.
</p>

<pre class="legacy-code"><code class="language-bash">$ pip install -r requirements.txt</code></pre>

<p class="basic-text-box">
  flask 는 후에 만들 api 서버의 프레임워크이고 tensorflow는 딥러닝 라이브러리이고 pillow는 파이썬 이미지 라이브러리의 유지 보수 버전이고 scipy는 학습시키려고 하니까 설치하라고 하더라고요?! 뭔지는 잘 모르겠네요.
</p>

<p class="basic-text-box">
  이제 본격적으로 코드를 볼까요
</p>

<pre class="legacy-code"><code class="language-python">// train_model.py
import tensorflow as tf
from tensorflow.keras.preprocessing.image import ImageDataGenerator
from tensorflow.keras.applications import ResNet50
from tensorflow.keras.layers import Dense, GlobalAveragePooling2D
from tensorflow.keras.models import Model
from tensorflow.keras.optimizers import Adam

# 데이터 경로 설정
train_dir = &#x27;dataset/train&#x27;
val_dir = &#x27;dataset/validation&#x27;

# 데이터 증강 및 전처리
train_datagen = ImageDataGenerator(
    rescale=1./255,
    shear_range=0.2,
    zoom_range=0.2,
    rotation_range=40,
    width_shift_range=0.2,
    height_shift_range=0.2,
    horizontal_flip=True,
    fill_mode=&#x27;nearest&#x27;
)

val_datagen = ImageDataGenerator(rescale=1./255)

train_generator = train_datagen.flow_from_directory(
    train_dir,
    target_size=(150, 150),
    batch_size=32,
    class_mode=&#x27;binary&#x27;
)

val_generator = val_datagen.flow_from_directory(
    val_dir,
    target_size=(150, 150),
    batch_size=32,
    class_mode=&#x27;binary&#x27;
)

# 사전 학습된 ResNet50 모델 로드
base_model = ResNet50(weights=&#x27;imagenet&#x27;, include_top=False)

# 모델 아키텍처 수정
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(1024, activation=&#x27;relu&#x27;)(x)
predictions = Dense(1, activation=&#x27;sigmoid&#x27;)(x)

model = Model(inputs=base_model.input, outputs=predictions)

# 모델 컴파일
model.compile(optimizer=Adam(learning_rate=0.0001), loss=&#x27;binary_crossentropy&#x27;, metrics=[&#x27;accuracy&#x27;])

# 모델 학습
model.fit(
    train_generator,
    validation_data=val_generator,
    epochs=10
)

# 모델 저장
model.save(&#x27;cat_detector_model.keras&#x27;)</code></pre>

<p class="basic-text-box">
  짜잔! 뭔가 생각보다 간단하고 그럴싸해 보이죠?!
  사실 ChatGPT가 만들어 준 코드라 뭔지 저도 잘 모릅니다..
</p>

<p class="basic-text-box">
  그래도 코드를 좀 알아야 뭘 할 수 있겠죠?
</p>

<pre class="legacy-code"><code class="language-python"># 데이터 경로 설정
train_dir = &#x27;dataset/train&#x27;
val_dir = &#x27;dataset/validation&#x27;</code></pre>

<p class="basic-text-box">
  주석 그대로 데이터 셋 이미지가 있는 디렉토리 경로 입니다.
</p>

<pre class="legacy-code"><code class="language-python"># 데이터 증강 및 전처리
train_datagen = ImageDataGenerator(
    rescale=1./255,
    shear_range=0.2,
    zoom_range=0.2,
    rotation_range=40,
    width_shift_range=0.2,
    height_shift_range=0.2,
    horizontal_flip=True,
    fill_mode=&#x27;nearest&#x27;
)

val_datagen = ImageDataGenerator(rescale=1./255)

train_generator = train_datagen.flow_from_directory(
    train_dir,
    target_size=(150, 150),
    batch_size=32,
    class_mode=&#x27;binary&#x27;
)

val_generator = val_datagen.flow_from_directory(
    val_dir,
    target_size=(150, 150),
    batch_size=32,
    class_mode=&#x27;binary&#x27;
)</code></pre>

<p class="basic-text-box">
  ImageDataGenerator는 이미지의 크기가 일정하지 않을때, 이미지의 크기를 동일하게 만들어주고 여러가지 옵션의 이미지의 양을 늘려서 모델의 성능을 올려주는 역할을 합니다. 위 코드를 짧게 살펴보면 'shear_range' 무작위로 기울기를 변형한 이미지를 추가하고(찌그러트림), 'zoom_range' 무작위 이미지를 확대하거나 축소한 이미지를, 그리고 'horizontal_flip'는 무작위 이미지를 좌우반전한 이미지가 전달됩니다. 그리고 'target_size'로 이미지의 사이즈는 150x150으로 동일하게 합니다.
</p>

<pre class="legacy-code"><code class="language-python"># 사전 학습된 ResNet50 모델 로드
base_model = ResNet50(weights=&#x27;imagenet&#x27;, include_top=False)</code></pre>

<p class="basic-text-box">
  'ResNet50'라는 모델을 기본 학습 모델로 사용하고 있는데요. 'ResNet50'는 ResNet 계열의 딥러닝 모델로 이미지 인식 및 분류 작업에 많이 사용되는 모델입니다.
</p>
<p class="basic-text-box">
  그리고 'ResNet50'의 메커니즘이나 특징을 이해하는 건..
저의 프로젝트 의지를 현격하게 저하시킬 가능성이 농후하기 때문에 여기까지..
</p>

<pre class="legacy-code"><code class="language-python"># 모델 아키텍처 수정
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(1024, activation=&#x27;relu&#x27;)(x)
predictions = Dense(1, activation=&#x27;sigmoid&#x27;)(x)</code></pre>

<p class="basic-text-box">
'x = GlobalAveragePooling2D()(x)'
- 전역 평균 풀링 레이어를 추가하여 공간적 크기를 줄입니다.
'x = Dense(1024, activation='relu')(x)'
- 1024개의 뉴런과 ReLU 활성화 함수를 가진 완전 연결 레이어를 추가합니다.
'predictions = Dense(1, activation='sigmoid')(x)'
- 1개의 뉴런과 sigmoid 활성화 함수를 가진 출력 레이어를 추가합니다. 이 레이어는 이진 분류를 위해 사용됩니다.
</p>

<p class="left-line-box">
  무슨 말인지 하나도 모르겠습니다. 
괜찮습니다. 차차 알아가기면 되니까요.
</p>

<pre class="legacy-code"><code class="language-python"># 모델 학습
model.fit(
    train_generator,
    validation_data=val_generator,
    epochs=10
)</code></pre>

<p class="basic-text-box">
train_generator: 학습 데이터 생성기입니다.
validation_data=val_generator: 검증 데이터 생성기입니다.
epochs=10: 에포크 수를 10으로 설정합니다.
</p>

<p class="basic-text-box">
  여기서 에포크는 학습 데이터 셋을 몇번 반복해서 학습시킬지를 나타냅니다. 예를 들어서 학습 데이터 셋이 100개고 epochs 수가 10이라면 총 1000개의 이미지를 학습합니다. 근데 이게 또 너무 많으면 훈련 데이터가 과적합해서 안좋을 수도 있어서 적당한 수치를 맞추는게 중요하다고 합니다.
</p>

<p class="basic-text-box">
  이제 한번 코드를 실행해 볼까요?
</p>

<pre class="legacy-code"><code class="language-bash">$ python3 train_model.py</code></pre>


<p class="basic-text-box">
  학습을 하면 아래와 같이 로그가 찍히는데요.
</p>

<pre class="legacy-code"><code class="language-bash">accuracy: 0.9926 - loss: 0.0643 - val_accuracy: 0.5000 - val_loss: 0.7365</code></pre>

<p class="basic-text-box">
  각각 'accuracy' 학습 데이터의 정확도, 'loss' 학습 데이터의 손실, 'val_accuracy' 검증 데이터의 모델 정확도, 'val_loss' 검증 데이터셋의 모델 손실값으로, 대략 위 데이터는 모델이 데이터셋을 잘 예측했지만, 예측은 50%에다가 검증 데이터 손실도 0.7365로 굉장히 높은데요.
</p>

<p class="basic-text-box">
  이렇게 되면 검증 데이터 손실이 너무 커서 잘 맞추지 못합니다..
