<h3>2. Serverless 설정</h3>
<p class="basic-text-box">
          일단 필요한 것들 먼저 설치해 줄까요?</p>

<pre class="legacy-code"><code class="language-bash">$ npm i -g serverless
$ npm i @vendia/serverless-express aws-lambda
$ npm i -D @types/aws-lambda</code></pre>
<p class="basic-text-box">
          다음으로 람다 핸들러 함수를 만들어 줄게요.</p>
<p class="left-line-box">
          <a href="https://docs.nestjs.com/faq/serverless#example-integration" target="_blank" rel="noopener noreferrer">https://docs.nestjs.com/faq/serverless#example-integration</a></p>

<pre class="legacy-code"><code class="language-javascript">// /src/lambda.ts
import { NestFactory } from &#x27;@nestjs/core&#x27;;
import serverlessExpress from &#x27;@vendia/serverless-express&#x27;;
import { Callback, Context, Handler } from &#x27;aws-lambda&#x27;;

import { AppModule } from &#x27;./app.module&#x27;;

let server: Handler;

async function bootstrap(): Promise&lt;Handler&gt; {
  const app = await NestFactory.create(AppModule);
  await app.init();

  const expressApp = app.getHttpAdapter().getInstance();
  return serverlessExpress({ app: expressApp });
}

export const handler: Handler = async (
  event: any,
  context: Context,
  callback: Callback,
) =&gt; {
  server = server ?? (await bootstrap());
  return server(event, context, callback);
};</code></pre>
<p class="basic-text-box">
          그리고 serverless 설정 파일을 만들어 줄게요.</p>

<pre class="legacy-code"><code class="language-bash"># /serverless.yaml
service: nest-serverless-example

frameworkVersion: &#x27;3&#x27;

plugins:

provider:
  name: aws
  region: ap-northeast-2
  runtime: nodejs16.x

functions:
  api:
    handler: dist/lambda.handler
    events:
      - http:
          method: any
          path: /{proxy+}</code></pre>
<p class="basic-text-box">
          마지막으로 타입스크립트 설정을 수정해 줄게요.</p>

<pre class="legacy-code"><code class="language-javascript">// /serverless.yaml
{
  &quot;compilerOptions&quot;: {

    &quot;sourceMap&quot;: true,
    &quot;outDir&quot;: &quot;./dist&quot;,
    &quot;baseUrl&quot;: &quot;./&quot;,
    // &quot;incremental&quot;: true,
    // &quot;tsBuildInfoFile&quot;: &quot;.tsbuildinfo&quot;,
    &quot;skipLibCheck&quot;: true,

<p class="basic-text-box">
          음.. 기본 설정에서 많이 바꾸진 않았는데요.</p>
<p class="basic-text-box">
          우선 'incremental'를 사용하지 않았어요. 'incremental'은 마지막 컴파일에 프로젝트에 대한 정보를 저장해서 프로젝트 변경을 효과적으로 동작하게 하는 기능인 거 같은데요.
기억이 잘 안 나는데 뭔가 오류가 떠서... 당장 필수 옵션은 아니라 일단 빼놓고 했어요.</p>
<p class="left-line-box">
          <a href="https://www.typescriptlang.org/docs/handbook/release-notes/typescript-3-4.html#faster-subsequent-builds-with-the---incremental-flag" target="_blank" rel="noopener noreferrer">https://www.typescriptlang.org/docs/handbook/release-notes/typescript-3-4.html#faster-subsequent-builds-with-the---incremental-flag</a></p>
<p class="basic-text-box">
          그리고 'esModuleInterop'와 'allowJs'를 true로 선언해 주었습니다.</p>
<p class="left-line-box">
          'esModuleInterop' - CommonJS 모듈을 가져올 수 있게 해줍니다.
<a href="https://www.typescriptlang.org/tsconfig#esModuleInterop" target="_blank" rel="noopener noreferrer">https://www.typescriptlang.org/tsconfig#esModuleInterop</a>
'allowJs' = 자바스크립트 파일을 가져올 수 있게 해줍니다.
<a href="https://www.typescriptlang.org/tsconfig#allowJs" target="_blank" rel="noopener noreferrer">https://www.typescriptlang.org/tsconfig#allowJs</a></p>

    TypeOrmModule.forRoot({
      type: &#x27;mysql&#x27;,

      username: process.env.DB_USERNAME,
      password: process.env.DB_PASSWORD,
      database: process.env.DB_DATABASE,
      entities: [],
      synchronize: true,

  ],

<h3>7. Role 수정</h3>
<p class="basic-text-box">
          다음으로 Role을 수정할건데요, Role을 수정하는 이유는 RDS에 해당 Lambda를 허용해주려면 보안 그룹을 설정해줘야 하는데, 그럴려면 기본적으로 설정되어 있는 Role에 추가 권한이 필요하답니다.</p>
<p class="basic-text-box">
          Lambda 설정에서 '구성' -&gt; '권한' -&gt; '실행 역할' 에서 역할 이름을 눌러 IAM으로 이동합니다.</p>
<figure><img style="max-width: 100%;" src="/wp-content/uploads/2023/05/nest-6.jpg" alt=""></figure>
<p class="basic-text-box">
          '권한' -&gt; '권한 정책'에서 '정책 이름'을 선택해서 '편집' 버튼을 눌러서 아래 내용을 추가해 주세요.</p>
<figure><img style="max-width: 100%;" src="/wp-content/uploads/2023/05/nest-7.jpg" alt=""></figure>
