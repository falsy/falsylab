<p class="basic-text-box">webpack3 버전이 릴리즈 된지도 어느덧 수개월이 지나 이미 4버전 알파가 올라오고 있는 시점이지만.. 아직 서비스 중인 프로젝트는 2버전을 사용하고 있어서 3, 4 버전을 알아보기 전에 2버전의 내용을 간단하게나마 정리해보려 합니다.
예제 코드: <a href="https://github.com/falsy/blog-post-example/tree/master/webpack2-quickstart" target="_blank" rel="noopener noreferrer">https://github.com/falsy/blog-post-example/tree/master/webpack2-quickstart</a>
(예제 코드라고 할것도 없지만..)</p>

<h3>1. 패키지 설정 및 설치</h3>
<p class="sub-title-text">1-1. init</p>

<p class="sub-title-text">1-4. html-webpack-plugin 플러그인 설치</p>
 
<pre class="legacy-code"><code class="language-default">$ npm install html-webpack-plugin --save-dev</code></pre>

<pre class="legacy-code"><code class="language-default">$ vi index.js</code></pre> 

<pre class="legacy-code"><code class="language-javascript">document.write(&#x27; world&#x27;);</code></pre> 

<p class="sub-title-text">2-3. webpack.config.js</p>
 
<pre class="legacy-code"><code class="language-default">$ vi webpack.config.js</code></pre> 
 
<pre class="legacy-code"><code class="language-javascript">&#x27;use strict&#x27;;

var webpack = require(&#x27;webpack&#x27;);
var HtmlWebpackPlugin = require(&#x27;html-webpack-plugin&#x27;);

module.exports = function makeWebpackConfig() {
  var config = {};
  
  config.entry = {
    app: &#x27;./index.js&#x27;,
  };

  config.output = {
    path: __dirname + &#x27;/build&#x27;,
    filename: &#x27;cheolguso.bundle.js&#x27;
  };

  config.devtool = &#x27;eval-source-map&#x27;;

  config.module = {};

  config.plugins = [
    new webpack.optimize.UglifyJsPlugin(),
    new HtmlWebpackPlugin({
      template: &#x27;./index.html&#x27;,
      inject: &#x27;body&#x27;
    })
  ];

  return config;
}();</code></pre>

<h3>4. webpack 설정들과 간단한 설명</h3>
<p class="sub-title-text">4-1. entry, output</p>
<p class="basic-text-box">entry는 몇가지 형태로 존재하는데, 그 이해를 위해선 output도 함께 보는 것이 좋습니다.</p>
 
<pre class="legacy-code"><code class="language-javascript">// 1.
config.entry = &#x27;./index.js&#x27;;
config.output = {
  path: __dirname + &#x27;/build&#x27;,
  filename: &#x27;cheolguso.bundle.js&#x27;
}</code></pre> 
 
<pre class="legacy-code"><code class="language-javascript">// 2.
config.entry = [&#x27;./index.js&#x27;, &#x27;./addScript.js&#x27;];
config.output = {
  path: __dirname + &#x27;/build&#x27;,
  filename: &#x27;cheolguso.bundle.js&#x27;
}</code></pre> 
 
<pre class="legacy-code"><code class="language-javascript">// 3.
config.entry = {
  index : &#x27;./index.js&#x27;, 
  addScript : &#x27;./addScript.js&#x27;
};
config.output = {
  path: __dirname + &#x27;/build&#x27;,
  filename: &#x27;[name].bundle.js&#x27;
}
// 여기에서 [name]은 entry객체의 키값이 됩니다. (eg. index, addScript)</code></pre> 

<p class="sub-title-text">4-2. devtool</p>
 
<pre class="legacy-code"><code class="language-javascript">config.devtool = &#x27;eval-source-map&#x27;;</code></pre> 

<p class="basic-text-box">압축, 난독화, es6+ 의 트랜스파일 등의 작업들로 어려워지는 디버깅을 소스맵을 통해 조금 수월하게 할 수 있는 옵션으로 이미 여러가지 옵션이 있으며 플러그인을 통해 더 확장되는 것으로 보입니다.
개인적으로는 angular1 + babel을 사용한 프로젝트에서 <span class="bg-point-text">eval</span> 이 포함되지 않는 옵션은 알 수 없는 오류가 발생해서 실험해보지 못하였으며, 단순히 결과적으로 배포를 위한 번들을 만듦에 있어, <span class="bg-point-text">eval-source-map</span> 에서 2.7mb 였던 번들의 크기가 <span class="bg-point-text">eval</span>에서 830kb 로 줄어드는 것을 알 수 있었습니다.</p>

<p class="left-line-box">아직 옵션들 하나 하나의 정확한 차이는 알지못합니다..
이부분은 webpack v3(또는 v4) 버전의 글을 작성할때 추가하도록 하겠습니다.</p>

<p class="sub-title-text">4-3. module</p>
 
<pre class="legacy-code"><code class="language-javascript">config.module = {
  rules: [{
    test: /\.js$/,
    exclude: /node_modules/,
    use: {
      loader: &#x27;babel-loader&#x27;,
      query: {
        presets: [&#x27;es2015&#x27;]
      }
    }
  }, {
    test: /\.less$/,
    use: [
      {loader: &quot;style-loader&quot;},
      {loader: &quot;css-loader&quot;, options: {sourceMap: true}},
      {loader: &quot;less-loader&quot;, options: {sourceMap: true}}
    ]
  }]
};</code></pre> 

<p class="basic-text-box">예를 들어 위와 같이 설정한다면, es6 -> es5로 less는 css 트랜스파일 됩니다.</p>
<p class="left-line-box">babel-loader, style-loader, css-loader, less-loader 는 추가로 설치해야 합니다</p>

<p class="sub-title-text">4-4. plugin</p>
 
<pre class="legacy-code"><code class="language-javascript">config.plugins = [
  new webpack.optimize.UglifyJsPlugin()
];</code></pre> 

<p class="basic-text-box">이름 그대로 플러그인을 설정합니다.
UglifyJsPlugin 플러그인은 자바스크립트 코드를 압축해줍니다.</p>
