<div id="review_text">
<p class="basic-text-box">어쩌면 워드프레스에 가장 기본은 포스트 타입이 아닐까 생각이 듭니다. 기본적으로 워드프레스에는 'post'와 'page'의 포스트 타입이 존재합니다. 하지만 여러 사이트를 개발하다 보면 두개의 포스트 타입으로는 부족한 경우가 많습니다. 실제로도 많은 테마와 플러그인에서 포스트 타입을 추가하여 다양한 기능으로 사용되어 집니다. 아래의 예를 통해 아주 간단히 'portfolio'라는 이름의 포스트타입을 추가해 보도록 하겠습니다.</p>
<p class="left-line-box">
그리고 추가한 포스트 타입에 'genre'라는 텍소노미를 추가해 보도록 하겠습니다.
(워드프레스에 기본으로 존재하는 포스트타입 'post'의 텍소노미는 'category'입니다.)
</p>

<h3>소스보기 - 포스트타입 추가</h3>

<pre class="legacy-code"><code class="language-php">[functions.php]

add_action(&#x27;init&#x27;, &#x27;cgs_portfolio_init&#x27;);

function cgs_portfolio_init(){
	$labels = array (
		&#x27;name&#x27;               =&gt; &#x27;Portfolio&#x27;,
		&#x27;singular_name&#x27;      =&gt; &#x27;Portfolio&#x27;,
		&#x27;menu_name&#x27;          =&gt; &#x27;포트폴리오&#x27;,
		&#x27;name_admin_bar&#x27;     =&gt; &#x27;Portfolio&#x27;,
		&#x27;add_new&#x27;            =&gt; &#x27;포트폴리오 추가&#x27;,
		&#x27;add_new_item&#x27;       =&gt; &#x27;새로운 포트폴리오 추가&#x27;,
		&#x27;new_item&#x27;           =&gt; &#x27;새로운 포트폴리오&#x27;,
		&#x27;edit_item&#x27;          =&gt; &#x27;포트폴리오 편집&#x27;,
		&#x27;view_item&#x27;          =&gt; &#x27;포트폴리오 보기&#x27;,
		&#x27;all_items&#x27;          =&gt; &#x27;모든 포트폴리오&#x27;,
		&#x27;search_items&#x27;       =&gt; &#x27;포트폴리오 검색&#x27;
	);
	$args = array(
		&#x27;labels&#x27;             =&gt; $labels,
		&#x27;public&#x27;             =&gt; true,
		&#x27;publicly_queryable&#x27; =&gt; true,
		&#x27;show_ui&#x27;            =&gt; true,
		&#x27;show_in_menu&#x27;       =&gt; true,
		&#x27;query_var&#x27;          =&gt; true,
		&#x27;rewrite&#x27;            =&gt; array( &#x27;slug&#x27; =&gt; &#x27;portfolio&#x27; ),
		&#x27;capability_type&#x27;    =&gt; &#x27;post&#x27;,
		&#x27;has_archive&#x27;        =&gt; true,
		&#x27;hierarchical&#x27;       =&gt; false,
		&#x27;menu_position&#x27;      =&gt; 7,
		&#x27;supports&#x27;           =&gt; array( &#x27;title&#x27;, &#x27;editor&#x27;, &#x27;author&#x27;, &#x27;thumbnail&#x27;, &#x27;excerpt&#x27;, &#x27;comments&#x27; )
	);
	register_post_type( &#x27;portfolio&#x27;, $args );
}</code></pre>

<p class="basic-text-box">여기에서 'rewrite'의 'slug'는 해당 포스트 타입의 포스트 싱글 페이지의 URL 경로로 사용됩니다.
(예: https://cheolguso.com/<span class="highlight_color2">portfolio</span>/abcabc/)
그리고 'supports'는 해당 포스트 타입의 포스트의 편집 페이지에서 사용할 옵션?을 선택적으로 사용할 수 있습니다.</p>

<h3>소스보기 - 텍소노미 추가</h3>

<pre class="legacy-code"><code class="language-php">[functions.php]

add_action(&#x27;init&#x27;, &#x27;cgs_taxonomies_init&#x27;);

function cgs_taxonomies_init(){
	$labels = array(
		&#x27;name&#x27;              =&gt; &#x27;분류&#x27;,
		&#x27;singular_name&#x27;     =&gt; &#x27;분류&#x27;,
		&#x27;search_items&#x27;      =&gt; &#x27;분류 검색&#x27;,
		&#x27;all_items&#x27;         =&gt; &#x27;All Genres&#x27;,
		&#x27;parent_item&#x27;       =&gt; &#x27;Parent Genre&#x27;,
		&#x27;parent_item_colon&#x27; =&gt; &#x27;Parent Genre:&#x27;,
		&#x27;edit_item&#x27;         =&gt; &#x27;분류 수정&#x27;,
		&#x27;update_item&#x27;       =&gt; &#x27;분류 저장&#x27;,
		&#x27;add_new_item&#x27;      =&gt; &#x27;분류 추가&#x27;,
		&#x27;new_item_name&#x27;     =&gt; &#x27;새로운 분류 추가&#x27;,
		&#x27;menu_name&#x27;         =&gt; &#x27;포트폴리오 분류&#x27;,
	);
	$args = array(
		&#x27;hierarchical&#x27;      =&gt; true,
		&#x27;labels&#x27;            =&gt; $labels,
		&#x27;show_ui&#x27;           =&gt; true,
		&#x27;show_admin_column&#x27; =&gt; true,
		&#x27;query_var&#x27;         =&gt; true,
		&#x27;rewrite&#x27;           =&gt; array( &#x27;slug&#x27; =&gt; &#x27;genre&#x27; ),
	);
	register_taxonomy( &#x27;genre&#x27;, array( &#x27;portfolio&#x27; ), $args );
}</code></pre>

<p class="basic-text-box">'register_taxonomy()' 의 2번째 인자값으로 해당 분류가 적용될 포스트 타입의 이름을 적어주면 됩니다.</p>
