저는 막대를 클릭하면 클릭한 막대에만 색이 변하게 해봤답니다.</p>
<p class="basic-text-box">
  <iframe width="100%" height="500px" src="//jsfiddle.net/falsy/ubLm459r/embedded/js,html,result/" allowfullscreen="allowfullscreen" allowpaymentrequest="" frameborder="0"></iframe></p>
<p class="basic-text-box">
  간단하게 달라진 부분만 살펴보면,</p>

<pre class="legacy-code"><code class="language-javascript">...

const handleClickRect = (d, i) =&gt; {
  svg.selectAll(&#x27;rect&#x27;).each(function(d, j) {
    if(j === i) d3.select(this).style(&#x27;fill&#x27;, pointColor);
    else d3.select(this).style(&#x27;fill&#x27;, baseColor);
  });
};

...

svg.append(&#x27;g&#x27;)
  .selectAll(&#x27;rect&#x27;).data(data).enter().append(&#x27;rect&#x27;)
  .attr(&#x27;x&#x27;, d =&gt; x(d.name))
  .attr(&#x27;y&#x27;, d =&gt; y(d.value))
  .attr(&#x27;height&#x27;, d =&gt; y(0) - y(d.value))
  .attr(&quot;rx&quot;, 15)
  .attr(&#x27;width&#x27;, x.bandwidth())
  .attr(&#x27;fill&#x27;, baseColor)
  .attr(&#x27;data-x&#x27;, d =&gt; d.name)
  .attr(&#x27;data-y&#x27;, d =&gt; d.value)
  .on(&quot;click&quot;, handleClickRect);

svg.node();
handleClickRect(null, data.length - 1);</code></pre>
<p class="basic-text-box">
  음.. 이벤트를 추가하는건 간단해요. .on()으로 콜백 함수를 등록할 수 있답니다.
그리고 콜백 함수에는 첫번째 인자로 .data()로 추가한 data값이, 그리고 두번째 인자로는 선택된 rect의 index값이 전달 된답니다.</p>
<p class="basic-text-box">
  그래서 해당 콜백 함수에서는 svg에 등록되었는 rect를 each로 순회해서 rect가 인자로 받은 index(선택 한 rect의 index)가 순회한 rect의 index가 같을때 해당 rect에 포인트 컬러를 채우고 나머지 rect에는 기본 컬러로 채워주도록 했답니다.</p>

<h3>2-2. Drag 이벤트 추가하기</h3>
<p class="basic-text-box">
  Drag 이벤트는 차트 영역 전체를 기준으로 동작해야 하니까 이벤트를 svg에 걸어줍니다.
그리고 d3에서 제공하는 drag() 라는 메서드를 사용했습니다.</p>

<pre class="legacy-code"><code class="language-javascript">...

svg.call(d3.drag().on(&quot;drag&quot;, handleDragShowTooltip));

...</code></pre>
<p class="left-line-box">
  d3.drag() 참고링크.
<a href="https://github.com/d3/d3-drag#api-reference" target="_blank" rel="noopener noreferrer">https://github.com/d3/d3-drag#api-reference</a></p>

<pre class="legacy-code"><code class="language-javascript">...

const showTooltip = (i) =&gt; {
  const targetData = data[i];
  const posX = Math.floor(x(targetData.date)) - Math.floor((tooltip.offsetWidth)/2);
  const posY = Math.floor(y(targetData.value)) - 35;

  tooltip.innerText = targetData.value;
  tooltip.style.cssText = `
    left: ${posX}px;
    top: ${posY}px;
    opacity: 1;
  `;
};

const handleDragShowTooltip = (d, i) =&gt; {
  const targetIdx = Math.floor(d3.event.x/xWidth) - 1;
  const periodIdx = targetIdx &lt; 0 ? 0 : targetIdx &gt; maxIdx ? maxIdx : targetIdx;
  showTooltip(periodIdx);
};

...</code></pre>
<p class="basic-text-box">
  그리고 위와 같이 이벤트 콜백 함수를 정의해 주었습니다.
한가지 특이한? 보통 DOM에 연결된 콜백 함수는 event라는 이벤트 객체를 사용할 수 있는데요, D3에서 등록한 이벤트는 'd3.event'라는 이벤트 객체를 사용할 수 있답니다.</p>
