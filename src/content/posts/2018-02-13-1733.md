<h3>4. Cloud Firestore</h3>
<p class="basic-text-box">
          <a href="https://console.firebase.google.com/u/1/?hl=ko" target="_blank" rel="noopener">Firebase console</a>에서 생성한 프로젝트를 선택한 후에 'DEVELOP' 탭의 'Database' 를 선택한 후 'Realtime Database'가 선택되어 있다면 'Cloud Firestore'를 선택합니다.
그리고 컬렉션과 문서, 필드를 추가합니다.</p>
<p class="left-line-box">
          저는 컬렉션 = note, 문서 = textarea, 필드 = text (string - 이곳에 값으로 스트링이 들어갑니다.)
위와 같이 작성하였습니다. 여기서 'note', 'textarea', 'text' 제가 임으로 정한 키값입니다.</p>
<p class="basic-text-box">
          간단하게 스트링 값만 불러오고 업데이트만 할 것이라 DB설정은 이걸로 끝입니다.</p>

<h3>5. Functions</h3>
<p class="basic-text-box">
          아까 초반에 Firebase를 설치한 'cheolguso-note' 디렉토리 안의 functions로 이동합니다.
그리고 여기에서는 몇가지 모듈을 설치해 줍니다.</p>

<pre class="legacy-code"><code class="language-default">// 편하게 디비에 접근할 수 있도록..
$ npm install --save firebase-admin
// 편하게 CORS를 설정할 수 있도록..
$ npm install --save cors</code></pre>
<p class="basic-text-box">
          그리고 index.js 파일을 아래와 같이 수정해줍니다.
- 2017-02-14 수정 -</p>

<pre class="legacy-code"><code class="language-javascript">// 기본 functions 모듈을 불러오고
const functions = require(&#x27;firebase-functions&#x27;);
// 다른 서비스에 쉽게 접근하기위한 모듈로 보입니다
const admin = require(&#x27;firebase-admin&#x27;);
admin.initializeApp(functions.config().firebase);

// api가 추가되더라도 디비 접근이 빈번하게 있을것 같아서 변수에 담아두고
const db = admin.firestore();
// 다른 도메인에서도 통신이 되도록 cors를 열어두고
const cors = require(&#x27;cors&#x27;)({origin: true});

// &#x27;/noteText&#x27; 라는 path 로 접근하면
exports.noteText = functions.https.onRequest((req, res) =&gt; {
  cors(req, res, () =&gt; {
    // 약간의 암호화... url 파람에 ?pw=1234 가 있어야만 하도록
    if(req.query.pw !== &#x27;1234&#x27;) return res.status(403).send(&#x27;권한이 없습니다.&#x27;);
    
    // 디비에 &#x27;note&#x27; 컬렉션에 &#x27;textarea&#x27; 문서를 불러오고
    db.collection(&#x27;note&#x27;).doc(&#x27;textarea&#x27;).get().then(doc =&gt; {
      // 성공하면 문서안의 &#x27;text&#x27;필드 값을 응답해 줍니다.
      return res.status(200).send({ reuslt : doc.data().text });
    }).catch(err =&gt; {
      console.log(&#x27;Error&#x27;, err);
    });
  });
});

// &#x27;/updateNoteText&#x27; 라는 path 로 접근하면
exports.updateNoteText = functions.https.onRequest((req, res) =&gt; {
  cors(req, res, () =&gt; {
    // 역시 약간의 암호화...
    if(req.query.pw !== &#x27;1234&#x27;) return res.status(403).send(&#x27;권한이 없습니다.&#x27;);
    
    // textarea 문서에 변화를 확인해서 업데이트가 되면 성공 응답을 보내줍니다.
    db.collection(&#x27;note&#x27;).doc(&#x27;textarea&#x27;).onSnapshot(doc =&gt; {
      return res.status(200).send({ result: true });
    });

    // 디비에 &#x27;note&#x27; 컬렉션에 &#x27;textarea&#x27; 문서의 &#x27;text&#x27; 필드의 값을 요청값 body의 text 값으로 업데이트 해줍니다.
    db.collection(&#x27;note&#x27;).doc(&#x27;textarea&#x27;).update({ text: req.body.text });
  });
});</code></pre>
<p class="basic-text-box">
          그리고 이제 Functions 를 적용합니다.</p>

<pre class="legacy-code"><code class="language-default">$ firebase deploy --only functions</code></pre>
<p class="left-line-box">
          만약에 <span class="bg-point-text">Error: functions predeploy error: Command terminated with non-zero exit code1</span> 이런 오류가 뜬다면, 프로젝트를 만든 폴더(ex. ../cheolguso-note)의 디렉토리 경로 중에 띄어쓰기를 포함한 폴더의 그 이름 사이 공백을 지우면 해결될 수 있습니다.</p>
<p class="basic-text-box">
          Functions까지 성공적으로 적용이 되었다면, functions의 url을 커맨드 창에서 알려주는데, 그부분을 복사해서
