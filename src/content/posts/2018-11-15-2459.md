<div id="review_text">

<p class="basic-text-box">
  그디어 본격적으로 React Native를 들어가서 오늘은 설치하고 실행해 보도록 하겠습니다.
  대부분의 정보는 <a href="https://facebook.github.io/react-native/docs/getting-started" target="_blank">https://facebook.github.io/react-native/docs/getting-started</a>와 동일합니다.
</p>

<p class="left-line-box">
  우선 앞으로의 글은 맥을 기준으로 하고, Android와 IOS를 모두 할 수 있는게 React Native의 하나의 장점이지만, IOS 앱으로만 이야기 하려 합니다.
  그리고 저는 현재 Node v8.11.2, Homebrew v1.8.2가 설치되어 있습니다.
</p>
<p class="left-line-box">
  아?! Xcode도 설치되어 있습니다.
</p>

<p class="basic-text-box">
  우선 Node와 Homebrew가 설치되어 있으니, watchman를 설치합니다.
</p>

 
<pre class="legacy-code"><code class="language-default">brew install watchman</code></pre> 


<p class="basic-text-box">
  다음으로 React Native를 전역에서 사용할 수 있도록 react-native-cli를 전역에 설치합니다.
</p>

 
<pre class="legacy-code"><code class="language-default">npm install -g react-native-cli</code></pre> 


<p class="left-line-box">
  퍼미션 오류가 난다면,
</p>

 
<pre class="legacy-code"><code class="language-default">sudo npm install -g react-native-cli</code></pre> 


<p class="left-line-box">
  글 쓴 시점으로 react-native-cli@2.0.1 가 설치되었습니다.
</p>


<p class="basic-text-box">
  이제 본격적으로 프로젝트를 만들 디렉토리를 만들고 React Native 프로젝트를 만들어 봅니다.
</p>

 
<pre class="legacy-code"><code class="language-default"> mkdir React-Native-Project // &#x27;React-Native-Project&#x27;라는 디렉토리를 만들고
 cd ./React-Native-Project // &#x27;React-Native-Project&#x27;로 이동합니다.</code></pre> 


 
<pre class="legacy-code"><code class="language-default">react-native init AwesomeProject // &#x27;AwesomeProject&#x27;라는 이름의 프로젝트를 만듭니다.</code></pre> 


 
<pre class="legacy-code"><code class="language-default">cd AwesomeProject // init이 완료되고, 새로 만들어진 &#x27;AwesomeProject&#x27; 디렉토리로 이동해서</code></pre> 


<p class="basic-text-box">
  이제 끝으로 run 합니다.
</p>
 
<pre class="legacy-code"><code class="language-default">react-native run-ios</code></pre>
