<p class="basic-text-box">Karma 테스트 러너로 ES6+ 의 코드를 유닛테스트 하는 방법에 대해 적어보려 합니다. 이 글에서는 추가로 Webpack과 Babel을 사용하고 테스트 프레임워크로 Jasmine을 사용하여 간단한 테스트 코드를 작성하고 Karma가 정상적으로 동작하는지 확인합니다.</p>
<p class="left-line-box">
  샘플코드 : <a href="https://github.com/falsy/blog-post-example/tree/master/karma-webpack-babel-quickstart" target="_blank" rel="noopener noreferrer">https://github.com/falsy/blog-post-example/tree/master/karma-webpack-babel-quickstart</a>
<h3>1. npm init</h3>
<pre class="legacy-code"><code class="language-default">$ npm init</code></pre>
<p class="basic-text-box">우선 init을 통해 기본적인 패키지 설정을 입력합니다.</p>

<h3>2. 모듈 설치</h3>
<p class="sub-title-text">2-1. Webpack</p>

<pre class="legacy-code"><code class="language-default">$ npm install --save-dev webpack webpack-cli webpack-dev-server html-webpack-plugin babel-loader</code></pre>
<p class="left-line-box">
  'webpack'은 그 'Webpack', 'webpack-cli' 커맨드 명령어를 편하게 해주는?(cli: Command Line Interface), 'webpack-dev-server'는 로컬에 서버를 열어주는?, 'html-webpack-plugin'은 Webpack으로 만들어진 번들 파일을 html 파일에 넣어주는(또는 가상의 index.html을 만들어주는) Webpack 플러그인?, 'babel-loader'는 Babel을 Webpack에서 사용할 수 있도록 불러오는?? 모듈입니다.
(이건.. 설명을 한것도 아니고 안한것도 아니네요..)

<p class="sub-title-text">2-2. Babel</p>

<pre class="legacy-code"><code class="language-default">$ npm install --save-dev babel-core babel-preset-env</code></pre>
<p class="left-line-box">
  'babel-core'는 그 'babel', 'babel-preset-env'는... 이전에 'babel-preset-es2015', 'babel-preset-es2016', 'babel-preset-es2017', 'babel-preset-latest' 같이 많이 사용되던 프리셋을 대체하는 프리셋 입니다. 대충.. ES6, ES7, ES8 -&gt; ES5로 트랜스파일 해주는 프리셋??

<p class="sub-title-text">2-3. Karma</p>

<pre class="legacy-code"><code class="language-default">$ npm install --save-dev karma karma-chrome-launcher jasmine-core karma-jasmine karma-webpack</code></pre>
<p class="left-line-box">
  'karma'은 그 'karma', 'karma-chrome-launcher'는 크롬 브라우저로 테스트하기 위한??, 'jasmine-core'는 그 BDD 테스트 프레임웍 Jasmin, 'karma-jasmine' 카르마와 재스민을 이어주고, 'karma-webpack'을 카르마와 웹팩을 이어줍니다.
<h3>3. 디렉토리 구조</h3>
<pre class="legacy-code"><code class="language-default">/src
  index.html
  index.js
/test
  testSpec.js
karma.conf.js
package.json
webpack.config.js</code></pre>
<p class="basic-text-box">이 글은 위와 같은 디렉토리 구조로 만들것 입니다.</p>

<h3>4. webpack.config.js 작성</h3>
<pre class="legacy-code"><code class="language-javascript">const HtmlWebpackPlugin = require(&#x27;html-webpack-plugin&#x27;);
const webpack = require(&#x27;webpack&#x27;);
const path = require(&#x27;path&#x27;);

module.exports = {
  // entry: &#x27;./src/index.js&#x27;, 시작점? 작성하지 않으면 기본값이 &#x27;./src/index.js&#x27;입니다.
  output: {
    path: path.resolve(__dirname, &#x27;dist&#x27;), //번들을 만들 위치?
    filename: &#x27;bundle.js&#x27; //번들파일이름
  },
  mode: &#x27;development&#x27;,
  module: {
    rules: [{
      test: /\.js?$/, // &#x27;.js&#x27;로 끝난 파일들이 대상
      loader: &#x27;babel-loader&#x27;, // 아까 설치한 바벨 모듈
      options: {
        presets: [&#x27;env&#x27;] // 아까 설치한 프리셋(&#x27;babel-preset-env&#x27;)
      },
      exclude: [&#x27;/node_modules&#x27;] // 제외할 대상
    }],
  },
  plugins: [
    // 아까 설치한 플러그인(&#x27;html-webpack-plugin&#x27;) &#x27;./src/index.js&#x27;에 번들파일을 인클루드 시켜줍니다.
    // new HtmlWebpackPlugin() : template 값을 입력하지 않으면 가상의 기본 index.html을 만들어 줍니다.
    new HtmlWebpackPlugin({template: &#x27;./src/index.html&#x27;})
  ]
};</code></pre>
<h3>5. karma.conf.js 작성</h3>
<pre class="legacy-code"><code class="language-javascript">module.exports = function(config) {
  config.set({
    basePath: &#x27;&#x27;,
    frameworks: [&#x27;jasmine&#x27;], // jasmine 프레임워크를 사용. 아까 설치한(&#x27;jasmine-core&#x27;, &#x27;karma-jasmine&#x27;)

    // 여기부터 기본 init에서 수정 사항
    // 웹팩 설정 가져오기?? 아까 설치한 모듈(&#x27;karma-webpack&#x27;)
    webpack: {
        mode: &#x27;development&#x27;,
        module: {
            rules: [{
              test: /\.js?$/,
              loader: &#x27;babel-loader&#x27;,
              options: {
                presets: [&#x27;env&#x27;]
              },
              exclude: [&#x27;/node_modules&#x27;]
            }]
        }
    },
    // 테스트할 대상 파일
    files: [
        // test 디렉토리에 Spec.js로 끝나는 파일
        // watched - 스펙 코드의 변화를 감지
        { pattern: &#x27;test/*Spec.js&#x27;, watched: true }
    ],
    preprocessors: {
        &#x27;test/*Spec.js&#x27;: [&#x27;webpack&#x27;], // &#x27;test/*Spec.js&#x27; 을 실행하기 전에 &#x27;webpack&#x27;을 선행??
    },
    // 여기까지 기존 init 이후 수정한 부분입니다.

    exclude: [
    ],
    reporters: [&#x27;progress&#x27;],
    port: 9876,
    colors: true,
    logLevel: config.LOG_INFO,
    autoWatch: true,
    browsers: [&#x27;Chrome&#x27;],
    singleRun: false,
    concurrency: Infinity
  })
}</code></pre>
<p class="left-line-box">위 코드의 주석으로 표시한 부분을 제외하면 대부분 init 기본값입니다.
(직접 아래의 명령어로 init 후 위 코드의 주석된 부분을 추가하셔도 됩니다.)
<pre class="legacy-code"><code class="language-default">// &#x27;karma-cli&#x27;를 설치했다면
$ karma init
// 설치하지 않았다면
$ ./node_modules/karma/bin/karma init</code></pre>

<h3>8. index.js 작성</h3>
<pre class="legacy-code"><code class="language-javascript">// src/index.js
class TestClass {

  constructor() {
    this.resetTestValue();
  }

  resetTestValue() {
    this.testValue = 0;
  }

  setTestValue(value) {
    this.testValue = value;
  }

}

export default new TestClass()</code></pre>
<h3>9. TestSpec.js 작성</h3>
<pre class="legacy-code"><code class="language-javascript">// test/TestSpec.js
import TestClass from &#x27;../src/index&#x27;; // srs/index.js 를 불러와서

describe(&#x27;Test 1&#x27;, function() {

  // it(..)이 실행될때마다 이전에 실행
  beforeEach(function() {
    // Reset
    TestClass.resetTestValue();
  });

  it(&#x27;Init Value&#x27;, function() {
    //TestClass.testValue 기본값은 &#x27;TestClass.resetTestValue()&#x27;이 실행된 이후기 때문에 0
    expect(TestClass.testValue).toEqual(0);
    // TestClass.testValue 가 0이면 success
  });

  it(&#x27;Set Test Value&#x27;, function() {
    //TestClass.testValue 기본값은 &#x27;TestClass.resetTestValue()&#x27;이 실행된 이후기 때문에 0
    const newValue = 2;
    TestClass.setTestValue(newValue);
    // &#x27;TestClass.testValue = 2&#x27; 가 됐을거에요
    expect(TestClass.testValue).toEqual(newValue);
    // TestClass.testValue 가 2 가 됐으면 success
  });

});</code></pre>
