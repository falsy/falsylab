<p class="view_box_title" style="margin-top: 30px;">Explanation</p>

<div id="review_text">
<p class="basic-text-box">간단하게 크롬 확장프로그램을 개발하는 방법부터 GCM(Google Cloud Messaging)을 이용하여 웹 알림(Notification)을 사용하는 방법에 대하여 적어보려 합니다. (웹 알림을 전송을 위한 API는 간단하게 노드를 통해 개발, 테스트합니다.)</p>
<p class="left-line-box">GCM은 FCM(Firebase Cloud Messaging)으로 새로운 버전이 나왔으며 FCM은 GCM의 인프라와 새로운 기능들을 담고 있습니다.</p>

<h3>1. 확장프로그램</h3>
<p class="basic-text-box">우선 빈 디렉토리를 만들고 'manifest.json'과 'index.html' 파일을 만듭니다. (저는 extensions-cgs 라는 이름으로 디렉토리를 만들었습니다.)</p>

<pre class="legacy-code"><code class="language-javascript">// extensions-cgs/manifest.json
{
  &quot;name&quot;: &quot;CGS-Helloword&quot;,
  &quot;description&quot; : &quot;helloword&quot;,
  &quot;version&quot;: &quot;1.0&quot;,
  &quot;browser_action&quot;: {
    &quot;default_popup&quot;: &quot;index.html&quot;
  },
  &quot;manifest_version&quot;: 2
}</code></pre>
<pre class="legacy-code"><code class="language-html">&lt;!-- extensions-cgs/index.html --&gt;
&lt;!DOCTYPE html&gt;
&lt;html&gt;
  &lt;head&gt;
    &lt;title&gt;Cheolguso Notification&lt;/title&gt;
    &lt;meta http-equiv=&quot;Content-Type&quot; content=&quot;text/html; charset=UTF-8&quot;&gt;
  &lt;/head&gt;
  &lt;body&gt;
    hello world
  &lt;/body&gt;
&lt;/html&gt;</code></pre>
<h3>2. 적용</h3>
<p class="basic-text-box">크롬 브라우저에서 주소창에 '<a href="chrome://extensions/" target="_blank" rel="noopener">chrome://extensions/</a>' 로 이동하여 '압축해제된 확장 프로그램을 로드합니다.' 를 선택하신 후 'extensions-cgs' 디렉토리를 불러오면 끝 입니다.
브라우저 오른쪽 위에 새로 등락한 확장프로그램을 선택하시면 'hello world' 문구를 확인 할 수 있습니다.</p>
<p class="left-line-box">manifest의 다양한 속성에 관한 정보는 크롬 디벨롭 사이트를 통해서 확인 하실 수 있습니다.
<a href="https://developer.chrome.com/extensions/manifest" target="_blank" rel="noopener">https://developer.chrome.com/extensions/manifest</a></p>

<h3>3. Firebase 프로젝트 등록 및 api-key 확인</h3>
<p class="basic-text-box"><a href="https://console.firebase.google.com/u/0/" target="_blank" rel="noopener">Firebase console</a> 페이지로 이동하여 로그인 후 프로젝트를 생성하고 프로젝트에 접속합니다.
왼쪽 메뉴의 'Project Overview' 옆의 톱니바퀴(settings)를 선택 -&gt; '프로젝트 설정' 선택 -&gt; '클라우드 메시징' 선택
이곳에서 확인하실 수 있는 '서버키', '발신자 ID'를 사용합니다.</p>

<h3>4. 알림 확장프로그램을 개발하기 전에 간단한 진행 순서</h3>
<p class="basic-text-box">1. 확장프로그램에서 GCM을 통해 메세지를 받을 수 있도록 설정합니다.
2. 확장프로그램에서 GCM에 등록하고 등록키 값을 확인합니다.
3. 해당 확장프로그램으로 알림을 전송할 수 있는 API를 만듭니다.</p>

<h3>5. manifest.json, index.html, script.js, background.js 수정 및 추가</h3>
<p class="basic-text-box">가로세로 각각 128px의 이미지를 하나 만들어 추가하였습니다.</p>

이제 만들어진 확장프로그램을 클릭하면 등록된 레지스트아이디를 출력하는 확장프로그램이 되었습니다.</p>

<h3>6. API 만들기 (for node.js)</h3>
<pre class="legacy-code"><code class="language-javascript">const express = require(&#x27;express&#x27;);
const app = express();
const bodyParser = require(&#x27;body-parser&#x27;);
const request = require(&#x27;request&#x27;);

app.use(bodyParser.json());

app.post(&#x27;/push&#x27;, (req, res) =&gt; {  
  const serverKey = &#x27;AAAAL8nArq...&#x27;; // Firebase console에서 확인한 서버키 값
  const auth = &#x27;key=&#x27; + serverKey;
  const key = req.body.key;
  const text = req.body.text;
  const registrationId = req.body.registrationId; // 추가한 구글 확장프로그램을 선택했을때 출력됐던 등록키 값
  request.post({
    url: &#x27;https://android.googleapis.com/gcm/send&#x27;,
    headers: {
      Authorization: auth
    },
    form: {
      registration_id : registrationId,
      [&#x27;data.&#x27;+key] : text
    }}, function(err, respon, body) {
      res.send();
    });
});

app.listen(3000, function () {
  console.log(&#x27;Example app listening on port 3000!&#x27;);
});</code></pre>
<p class="basic-text-box">이제 '<a href="https://www.getpostman.com/" target="_blank" rel="noopener">Postman</a>' 같은 툴을 사용해서 'localhost:3000/push'로 body에 json형태로 'registrationId', 'key', 'text' 값을 전송하면 알림이 전송됩니다.
끄읕.</p>
