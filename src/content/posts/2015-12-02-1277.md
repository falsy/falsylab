<div id="review_text">
<p class="basic-text-box">
자바스크립트의 이벤트 처리는 계층적인 DOM 구조에 중복적으로 실행되기도 하는데 이 현상을 이벤트 버블링이라고 합니다. 그리고 버블링으로 인해 예상하지 못한 결과를 얻게 되는 일을 자주 겪게 되는데, 그에 따른 방법을 정리해보았습니다.</p>
 
 
<h3>1. 부모에게 이벤트 전파되는 것을 막기</h3>
 
<pre class="legacy-code"><code class="language-html">&lt;body&gt;
	&lt;div id=&quot;parent&quot;&gt;
		&lt;div id=&quot;children&quot;&gt;클릭&lt;/p&gt;
	&lt;/div&gt;
&lt;/body&gt;</code></pre> 

 
<pre class="legacy-code"><code class="language-javascript">jQuery(document).ready(function($){
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;#parent&quot;, function(event){
		alert(&quot;Parent Click&quot;);
	});
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;#children&quot;, function(event){
		alert(&quot;Children Click&quot;);
	});
});</code></pre> 


<p class="basic-text-box">위와 같은 구조에서 '클릭'을 클릭하면 'Children Clcik" 알림창과 'Parent Clcik' 알림창이 중복되어 실행됩니다. 이렇게 이벤트가 부모에 전파되는 것을 막기위해 'event.stopPropagation()'를 사용할 수 있습니다.</p>

 
<pre class="legacy-code"><code class="language-javascript">jQuery(document).ready(function($){
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;#parent&quot;, function(event){
		alert(&quot;Parent Click&quot;);
		
	});
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;#children&quot;, function(event){
		alert(&quot;children Click&quot;);
		if(event.stopPropagation) event.stopPropagation(); //MOZILLA
		else event.cancelBubble = true; //IE
	});
});</code></pre> 


<h3>2. 같은 DOM에 걸린 이벤트 막기</h3>

 
<pre class="legacy-code"><code class="language-html">&lt;body&gt;
	&lt;div id=&quot;parent&quot;&gt;
		&lt;div id=&quot;children&quot;&gt;클릭&lt;/div&gt;
	&lt;/div&gt;
&lt;/body&gt;</code></pre>

 
<pre class="legacy-code"><code class="language-javascript">jQuery(document).ready(function($){
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;div&quot;, function(event){
		alert(&quot;Div Click&quot;);
	});
});</code></pre> 


<p class="basic-text-box">위와 같은 구조에서 '클릭'을 클릭하면 'Div Click" 알림창이 2번 중복 실행되는 것을 알 수 있습니다. 이렇게 동일한 DOM에 걸린 이벤트의 중복 실행을 'event.stopImmediatePropagation()'로 중지할 수 있습니다.</p>

 
<pre class="legacy-code"><code class="language-javascript">jQuery(document).ready(function($){
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;div&quot;, function(event){
		alert(&quot;Parent Click&quot;);
		if(event.stopImmediatePropagation) event.stopImmediatePropagation(); //MOZILLA
		else event.isImmediatePropagationEnabled = false; //IE
	});
});</code></pre> 


<h3>3. 기본 동작 중지하기</h3>

 
<pre class="legacy-code"><code class="language-html">&lt;body&gt;
	&lt;a href=&quot;#&quot;&gt;클릭&lt;/a&gt;
	&lt;!-- &lt;a href=&quot;#NULL&quot;&gt;클릭&lt;/a&gt; --&gt;
&lt;/body&gt;</code></pre> 
 
<pre class="legacy-code"><code class="language-javascript">jQuery(document).ready(function($){
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;a&quot;, function(event){
		alert(&quot;A click&quot;);
	});
});</code></pre> 

<p class="basic-text-box">그다지 예가 좋아보이진 않지만.. 위와 같은 구조에서 '클릭'을 클릭하면 'A click'이라는 알림창이 뜨고 페이지 스크롤이 최상단으로 이동하게 되며 URL의 마지막에 #에 추가됩니다. 하지만 'event.preventDefault()'를 사용하면 엘리먼트의 기본적인 동작을 중단시킬 수 있습니다.</p>

 
<pre class="legacy-code"><code class="language-javascript">jQuery(document).ready(function($){
	$(&quot;body&quot;).on(&quot;click&quot;, &quot;a&quot;, function(event){
		alert(&quot;A click&quot;);
		if(event.preventDefault) event.preventDefault(); //MOZILLA
		else event.returnValue = false; //IE
	});
});</code></pre>
