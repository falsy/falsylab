<p class="view_box_title" style="margin-top: 30px;">Explanation</p>

<div id="review_text">
<p style="margin-bottom: 30px;">오늘은 자바스크립트 객체의 복사에 관하여 알아 보려 합니다. 자바스크립트의 객체 복사에는 얕은 복사와 깊은 복사로 나뉘는데요. 먼저 얕은 복사를 하는 방법?? 에 대해 알아봅니다.</p>

<h3 style="border-top: 0;">1. 얕은 복사(Shallow Copy)</h3>
<p class="basic-text-box">얕은 복사와 깊은 복사의 차이는 복사하고자 하는 객체의 속성의 값으로 객체가 있을때, 그 내부 객체의 값에 대하여 참조 값을 복사하느냐 또는 그 값을 복사하느냐의 차이를 가지고 있는데요.
이렇게 적고 보니 더 헷갈릴 수 있을 거 같네요..
간단하게 예로 들어서 첫번째로는 직접 함수를 만들어서 얕은 복사를 해봅니다.

<p class="sub-title-text">1-1. 함수를 만들어서 사용</p>

<pre class="legacy-code"><code class="language-javascript">function shallowCopy(value) {
  const result = {};
 
  for(const key in value) {
    result[key] = value[key];
  }

  return result;
}

const testData = {a: 1, b: 2};
const copyData = shallowCopy(testData);

console.log(copyData);
// {a: 1, b: 2}</code></pre>
<p class="basic-text-box">다음은 ES6에 추가된 Object.assign() 메서드를 사용하는 방법입니다.
Object.assign() 메서드는 객체를 병합하거나 복사할때 사용하는데요.

<p class="sub-title-text">1-2. Object.assign() 메서드 사용</p>

<pre class="legacy-code"><code class="language-javascript">const testData = {a: 1, b: 2};
const copyData = Object.assign({}, testData);

console.log(copyData);
// {a: 1, b: 2}</code></pre>
<p class="basic-text-box">그리고 마지막으로 전개 연산자(펼침 연산자)를 사용하는 방법입니다. 역시 ES6 스펙에 정의되었습니다.</p>
<p class="sub-title-text">1-3. 전개 연산자 사용</p>

<pre class="legacy-code"><code class="language-javascript">const testData = {a: 1, b: 2};
const copyData = { ...testData };

console.log(copyData);
// {a: 1, b: 2}</code></pre>
<p class="basic-text-box">대략 이러한 방법들이 있는거 같아요.</p>
<p class="basic-text-box">그런데 아까 이야기 했듯이 복사하고자 하는 객체가 객체를 담고 있으면 참조 값을 복사하기 때문에 '복사 대상 객체'의 값이 바뀌면 '복사한 객체'의 값이 바뀌어요. 간단히 예를 들면 아래와 같아요.</p>

<pre class="legacy-code"><code class="language-javascript">function shallowCopy(value) {
  const result = {};
 
  for(const key in value) {
    result[key] = value[key];
  }

  return result;
}

const testData = {a: {aa: 1}, b: 2};
const copyData = shallowCopy(testData);
testData.a.aa = 2;

console.log(copyData);
// {a: {aa: 2}, b: 2}</code></pre>
<pre class="legacy-code"><code class="language-javascript">const testData = {a: {aa: 1}, b: 2};
const copyData2 = Object.assign({}, testData);
testData.a.aa = 2;

console.log(copyData2);
// {a: {aa: 2}, b: 2}</code></pre>
<pre class="legacy-code"><code class="language-javascript">const testData = {a: {aa: 1}, b: 2};
const copyData = { ...testData };
testData.a.aa = 2;

console.log(copyData);
// {a: {aa: 2}, b: 2}</code></pre>
<h3 style="border-top: 0;">2. 깊은 복사(Deep Copy)</h3>
<p class="basic-text-box">앞서 보았듯이 깊은 복사는 객체 안의 객체의 참조 값도 완전히 원시 데이터 값으로 복사하는 방법이겠죠?
우선 첫번째로 가장 간단하게 사용할 수 있는 방법은 JSON 객체를 사용하거나, JSON 객체와 eval() 메서드를 사용하는 방법이에요.

<p class="sub-title-text">2-1. JSON 객체 사용 ( + eval() 메서드 사용)</p>

<pre class="legacy-code"><code class="language-javascript">const testData = {a: {aa: 1}, b: 2};
const copyData = JSON.parse(JSON.stringify(testData));
testData.a.aa = 2;

console.log(copyData);
// {a: {aa: 1}, b: 2}</code></pre>
<pre class="legacy-code"><code class="language-javascript">const testData = {a: {aa: 1}, b: 2};
const copyData = eval(&#x27;(&#x27;+JSON.stringify(testData)+&#x27;)&#x27;);
testData.a.aa = 2;

console.log(copyData);
// {a: {aa: 1}, b: 2}</code></pre>
<p class="basic-text-box">JSON.stringify() 메서드로 객체의 데이터를 JSON 형태의 문자열로(원시 데이터)로 만들어서 복사한 후 JSON.parse() 또는 eval() 메서드를 사용해서 다시 객체로 만드는 방법입니다.
비숫해 보이는 이 둘을 함께 적은 건 '뭐가 더 빠를까?' 하는 생각이 들어서... 간단하게 실험을 해봤는데요.
<pre class="legacy-code"><code class="language-javascript">function test() {
	const aa = {};

	for(let i=0; i&lt;10000; i++) {
	 aa[&#x27;test&#x27;+i] = i*100;
	}

	const bb = JSON.stringify(aa);

	console.time();
	const cc = JSON.parse(bb);
	console.timeEnd();
}</code></pre>
<pre class="legacy-code"><code class="language-javascript">function test2() { 
	const aa = {};

	for(let i=0; i&lt;10000; i++) {
	 aa[&#x27;test&#x27;+i] = i*100;
	}

	const bb = JSON.stringify(aa);

	console.time();
	const cc = eval(&#x27;(&#x27;+bb+&#x27;)&#x27;);
	console.timeEnd();
}</code></pre>
<p class="basic-text-box">저는 크롬 v71.0.3578 과 Node v8.11.2 에서 두개의 함수를 만들어서 실행해 봤는데요. 크롬에서는 JSON.parse() 가 약 4s, 그리고 eval()는 약 8s로 JSON.parse()가 훨씬 빠르게 나왔어요. 그리고 노드에서는 JSON.parse()의 경우 2.2s, 3.6s, 3.6s, 3.6s, 2.1s ... 정도의 속도가 그리고 eval()은 6.6s, 5.7s, 3.3s, 0.2s, 0.2s...로 처음엔 느리고 함수를 실행할 수록 점점 더 빨라졌어요.</p>
<p class="left-line-box">왜지...? 하지만 점점 시간이 너무 늦어지고 있는 관계로...
여하튼 급하게 마무리를 지어보자면, 데이터나 브라우저에 따라서 조금씩 차이는 있겠지만 eval() 보단 JSON.parse() 쓰는게 좋을거 같아요. (MDN에서도 eval() 함수 사용의 위험에 대해 언급하는 것도 보이고요.)

<p class="basic-text-box">약간 뜬금없이 JSON.parse() 와 eval() 을 비교했는데요. 다시 본론으로 돌아가면 JSON 객체를 사용하는 법은 간편하지만 우선 성능적으로 좋지 못하고, 그리고 복사하는 객체의 속성 중 값이 함수이거나 undefined 인 경우 또 완전한 복사가 되지 않는다는 문제가 있답니다. 예를 들자면 아래와 같습니다.</p>

<pre class="legacy-code"><code class="language-javascript">const testData = {a: (a, b) =&gt; a + b, c: undefined};
const copyData = JSON.parse(JSON.stringify(testData));
console.log(copyData);
// {}</code></pre>
<p class="basic-text-box">다음으로 깊은 복사를 할 수 있는 함수를 만들어서 사용하는 방법입니다. 얕은 복사에서 사용한 함수와 거의 비슷하지만 객체의 속성의 값이 객체일때는 재귀를 사용하는 정도가 추가 됩니다.</p>
<p class="sub-title-text">2-2. 함수를 만들어서 사용</p>

<pre class="legacy-code"><code class="language-javascript">function deepCopy(value) {
  const result = {};
 
  for(const key in value) {
  	if(typeof value[key] === &#x27;object&#x27;) {
  		result[key] = deepCopy(value[key]);
  	} else {
  		result[key] = value[key];
  	}
  }

  return result;
}

const testData = {a: {aa: 1}, b: 2};
const copyData = deepCopy(testData);
testData.a.aa = 2;

console.log(copyData);
// {a: 1, b: 2}</code></pre>
<p class="basic-text-box">이렇게 함수를 만들어 사용하면 객체 속성의 값이 함수이거나 undefined여도 복사가 가능합니다.</p>

<pre class="legacy-code"><code class="language-javascript">function deepCopy(value) {
  const result = {};
 
  for(const key in value) {
  	if(typeof value[key] === &#x27;object&#x27;) {
  		result[key] = deepCopy(value[key]);
  	} else {
  		result[key] = value[key];
  	}
  }

  return result;
}

const testData = {a: (a, b) =&gt; a+b, b: undefined};
const copyData = deepCopy(testData);
console.log(copyData);
// {a: (a, b) =&gt; a+b, b: undefined}</code></pre>
<p class="basic-text-box">그리고 간단한 성능테스트</p>

<pre class="legacy-code"><code class="language-javascript">function test() {
	const aa = {};

	for(let i=0; i&lt;10000; i++) {
	 aa[&#x27;test&#x27;+i] = i*100;
	}

	console.time();
	const bb = JSON.parse(JSON.stringify(aa));
	console.timeEnd();
}</code></pre>
<pre class="legacy-code"><code class="language-javascript">function test2() { 
	const aa = {};

	for(let i=0; i&lt;10000; i++) {
	 aa[&#x27;test&#x27;+i] = i*100;
	}

	const deepCopy = value =&gt; {
	  const result = {};
	 
	  for(const key in value) {
	  	if(typeof value[key] === &#x27;object&#x27;) {
	  		result[key] = deepCopy(value[key]);
	  	} else {
	  		result[key] = value[key];
	  	}

<p class="basic-text-box">역시 동일하게 크롬 v71.0.3578 과 Node v8.11.2 에서 두개의 함수를 만들어서 실행해 보았는데요. 크롬에서 JSON 객체를 사용할 경우 7.7s, 7.1s, 9.6s, 6s, 7.3s, 6.5s... deepCopy 함수를 만들어 사용할 경우 4.1s, 4.2s, 2.6s, 2.5s ... 그리고 동일하게 노드에서는 JSON 객체는 4.5s, 4.5s, 4.6s, 4.4s, 4s ... deepCopy 함수는 2.9s, 3.4s, 3.8s, 2.5s, 2.1s ...</p>
