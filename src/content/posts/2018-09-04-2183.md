<p class="view_box_title" style="margin-top: 30px;">Explanation</p>

<div id="review_text">
<p class="basic-text-box">
Docker에 대해 1~2년 전부터 엄청 많이 들어서 이름만 익숙했었는데요. 최근에 들어서야 (조~금) 사용하게 되어 간단하게나마 docker를 설치하고 사용해보는 것에 대한 글을 적어 보려 합니다.
시중에 docker에 관련된 책도 많은 것으로 보아 그 사용이나 활용에 대해 많은 방법들이 있을 것 같아요, 하지만 저는 깊이 있게 사용하지 않고 간단하게 테스트 환경과 상용의 환경을 같게 해서 코드나 데이터의 무결성에 조금 도움이 되는?? 정도로만 사용하기 때문에 Docker에 대해 퀵스타트 정도로 얕게 적어 보려 합니다.
</p>
<p class="left-line-box">
  전에는 Vagrant로 가상 환경을 만들어서 작업을 했었는데요, 제가 생각하는 가장 큰 둘의 차이는 Vagrant는 모든 OS의 가상 환경을 만들 수 있고 Docker는 리눅스 기반의 환경만 가능합니다. 저는 서버 환경을 Ubuntu만 사용하기 때문에 아주 간단하게 비교했을 때 속도 면에서 훨씬 Docker가 빠르답니다.
</p>

<h3>1. Docker 설치하기</h3>
<p class="basic-text-box">
우선 <a href="https://www.docker.com/" target="_blank">https://www.docker.com/</a> 사이트로 이동하여 회원가입을 하고 docker를 설치합니다.
</p>
<p class="left-line-box">
  맥OS 기준입니다.
</p>

<img src="/wp-content/uploads/2018/09/11.png" alt="" style="max-width: 100%;" />
<p class="basic-text-box">1-1. Docker 홈페이지</p>

<img src="/wp-content/uploads/2018/09/22.png" alt="" style="max-width: 100%;" />
<p class="basic-text-box">1-2. Products > Docker Desktop 로 이동합니다.</p>

<img src="/wp-content/uploads/2018/09/33.png" alt="" style="max-width: 100%;" />
<p class="basic-text-box">1-3. 로그인 후 다운로드가 가능합니다. 회원이 아니라면 회원 가입 후 로그인 합니다.</p>

<img src="/wp-content/uploads/2018/09/44.png" alt="" style="max-width: 100%;" />
<p class="basic-text-box">1-4. Get Docker 버튼을 눌러 다운로드 한 후 설치하고, 실행해 줍니다.</p>


<p class="basic-text-box">1-5. 터미널을 열어주세요.</p>
<pre class="legacy-code"><code class="language-default">$ docker --version
# docker 버전 확인

$ docker run hello-world
# 지금은 이미지가 없으니까 Docker Hub에서 hello-world 라는 이미지를
# 이미지를 가져옵니다.

$ docker run -d -p 80:80 --name webserver nginx
# 80번 포트로 webserver 라는 컨테이너 이름으로 nginx 서버를 띄웁니다.

$ docker container ls
# 실행되고 있는 컨테이너의 정보를 봅니다.</code></pre>


<img src="/wp-content/uploads/2018/09/66.png" alt="" style="max-width: 100%;" />
<p class="basic-text-box">1-6. docker의 <a href="https://docs.docker.com/docker-for-mac/" target="_blank">Getting started</a>를 따라 진행하면 위와 같이 로컬 호스트 80번(기본값) 포트에 Nginx의 웹 페이지를 확인 할 수 있습니다.</p>

<h3>2. Node 서버 띄우기</h3>
<p class="basic-text-box">
2-1. 간단하게 디렉토리를 만들고 'npm init' 으로 패키지를 만듭니다. (express 설치)
</p>


<pre class="legacy-code"><code class="language-default">$ mkdir ./docker-node
$ cd ./docker-node
$ npm init
$ npm install --save express</code></pre> 


 
<pre class="legacy-code"><code class="language-javascript">// package.json
{
  &quot;name&quot;: &quot;docker-node&quot;,
  &quot;version&quot;: &quot;1.0.0&quot;,
  &quot;description&quot;: &quot;docker node test&quot;,
  &quot;main&quot;: &quot;index.js&quot;,
  &quot;scripts&quot;: {
    &quot;test&quot;: &quot;echo \&quot;Error: no test specified\&quot; &amp;&amp; exit 1&quot;
  },
  &quot;author&quot;: &quot;falsy&quot;,
  &quot;license&quot;: &quot;WTFPL&quot;,
  &quot;dependencies&quot;: {
    &quot;express&quot;: &quot;^4.16.3&quot;
  }
}</code></pre> 

<p class="basic-text-box">
  2-2. index.js 파일을 만듭니다.
</p>

 
<pre class="legacy-code"><code class="language-default">$ vi index.js</code></pre> 


 
<pre class="legacy-code"><code class="language-javascript">const express = require(&#x27;express&#x27;);
const app = express();

app.get(&#x27;/&#x27;, (req, res) =&gt; {
  res.send(&#x27;hello world&#x27;);
});

app.listen(80, () =&gt; {
  console.log(&#x27;test listening on port 80&#x27;);
});</code></pre> 


<p class="basic-text-box">
  2-3. 모듈 파일을 복사하지 않도록 .dockerignore 파일을 만듭니다.
</p>

 
<pre class="legacy-code"><code class="language-default">$ vi .dockerignore</code></pre> 


 
<pre class="legacy-code"><code class="language-default">node_modules/</code></pre> 


<p class="basic-text-box">
  2-4. Dockerfile 파일을 만듭니다.
</p>

 
<pre class="legacy-code"><code class="language-default">$ vi Dockerfile</code></pre> 


 
<pre class="legacy-code"><code class="language-default">FROM node:8
COPY . .
RUN npm install
EXPOSE 80
WORKDIR /

CMD node index.js</code></pre> 


<p class="basic-text-box">
  2-5. Docker 이미지를 만듭니다.
</p>

 
<pre class="legacy-code"><code class="language-default">$ docker build --tag docker-node:dev .</code></pre> 


<p class="basic-text-box">
  2-6. 이미지 생성이 끝나면 이미지가 잘만들어 졌는지 확인합니다.
</p>

 
<pre class="legacy-code"><code class="language-default">$ docker images
# docker-node</code></pre> 


<p class="basic-text-box">
  2-7. 생성한 이미지를 실행합니다.
</p>

 
<pre class="legacy-code"><code class="language-default">$ docker run --name docker-node-container -p 80:80 docker-node:dev</code></pre> 


<img src="/wp-content/uploads/2018/09/77.png" alt="" style="max-width: 100%;" />
<p class="basic-text-box">
  2-8. 이제 브라우저를 열고 localhost로 접속하면[포트 80번(기본값)] 위와 같이 'hello world'가 뜨는 걸 확인 할 수 있습니다.
</p>

<h3>3. 그 밖의 간단한 커맨드</h3>
<p class="basic-text-box">
3-1. 실행 중인 컨테이너 중지 및 삭제, 이미지 삭제
</p>
 
<pre class="legacy-code"><code class="language-default">$ docker stop docker-node-container
# &#x27;docker-node-container&#x27; 컨테이너 중지

$ docker container rm docker-node-container
# &#x27;docker-node-container&#x27; 컨테이너 삭제

$ docker image rm docker-node:dev
# &#x27;docker-node:dev&#x27; 이미지 삭제</code></pre>
