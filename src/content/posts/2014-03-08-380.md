간단하게 만들어보는 Select Box, IE8 에서도 동일한 효과를 줄 수 있다.

<span style="color: #71aaad;">예제 링크</span> : <a title="새창으로 보기" href="/preview/select/select.html" target="_blank" rel="noopener noreferrer">/preview/select/select.html</a>

<pre class="legacy-code"><code class="language-html">[HTML]

&lt;div id=&quot;select_box&quot;&gt;
    &lt;label for=&quot;color&quot;&gt;color&lt;/label&gt;
    &lt;select id=&quot;color&quot; title=&quot;select color&quot;&gt;
        &lt;option selected=&quot;selected&quot;&gt;color&lt;/option&gt;
        &lt;option&gt;red&lt;/option&gt;
        &lt;option&gt;blue&lt;/option&gt;
        &lt;option&gt;yellow&lt;/option&gt;
        &lt;option&gt;black&lt;/option&gt;
    &lt;/select&gt;
&lt;/div&gt;</code></pre>
<pre class="legacy-code"><code class="language-css">[CSS]

div#select_box {
    position: relative;
    width: 200px;
    height: 40px;
    background: url(select_arrow.png) 180px center no-repeat; /* 화살표 이미지 */
    border: 1px solid #E9DDDD;
}
div#select_box label {
    position: absolute;
    font-size: 14px;
    color: #a97228;
    top: 13px;
    left: 12px;
    letter-spacing: 1px;
}
div#select_box select#color {
    width: 100%;
    height: 40px;
    min-height: 40px;
    line-height: 40px;
    padding: 0 10px;
    opacity: 0;
    filter: alpha(opacity=0); /* IE 8 */
}</code></pre>
<pre class="legacy-code"><code class="language-javascript">[JAVASCRIPT]

jQuery(document).ready(function(){
    
    var select = $(&quot;select#color&quot;);
    
    select.change(function(){
        var select_name = $(this).children(&quot;option:selected&quot;).text();
        $(this).siblings(&quot;label&quot;).text(select_name);
    });
});</code></pre>
