이번 포스팅은, 저번에 serverless-nextjs 프로젝트를 임시로 스테이지 별로 배포하는 방법에서
커맨드를 사용한 조금이나마 더 나은 방법을 적어보려 합니다.</p>
<p class="left-line-box">
  참고) 이전 글.
<a href="/serverless-nextjs/" target="_blank" rel="noopener noreferrer">/serverless-nextjs/</a></p>

<h3>1. 환경변수</h3>
<p class="basic-text-box">
  기본적으로 serverless-nextjs 에서는 serverless.yml 파일에 ${env.XXX} 이렇게 환경 변수를 선언할 수 있는데요. 커맨드를 입력할때 'env XXX=test next' 이렇게 입력하면 위 ${env.XXX} 부분이 'test'로 동작한답니다.</p>

<pre class="legacy-code"><code class="language-javascript">// serverless.yml
falsyExempleServerlessNext:
  component: &quot;@sls-next/serverless-component@3.6.0&quot;
  inputs:
    roleArn: &quot;arn:aws:iam::123456789012:role/falsy-exemple-role&quot;
    bucketName: &quot;falsy-exemple-s3&quot;
    cloudfront:
      distributionId: ABCDEFG..
    name:
      defaultLambda: &quot;falsy-exemple-default-lambda&quot;
      apiLambda: &quot;falsy-exemple-api-lambda&quot;</code></pre>
<p class="basic-text-box">
  만약 기존에 위와 같이 있다면, dev와 prod로 나뉘어야 하는 부분을 환경 변수로 변경해줍니다.</p>

<pre class="legacy-code"><code class="language-javascript">// serverless.yml
falsyExempleServerlessNext:
  component: &quot;@sls-next/serverless-component@3.6.0&quot;
  inputs:
    roleArn: &quot;arn:aws:iam::123456789012:role/falsy-exemple-role&quot;
    bucketName: &quot;${env.BUCKET_NAME}&quot;
    cloudfront:
      distributionId: ${env.CROUDFRONT_ID}
    name:
      defaultLambda: &quot;${env.DEFAULT_LAMBDA}&quot;
      apiLambda: &quot;${env.API_LAMBDA}&quot;</code></pre>
<p class="basic-text-box">
  위와 같이 레이어에 따라 변경되어야 하는 부분을 변수로 만들어줍니다.</p>
<p class="left-line-box">
  사실 위와 같은 변수 선언이 예쁘게?? 익숙하게?? 보이지 않는데요.
예를 들면 bucketName을 'falsy-exemple-s3-${env.STAGE}' 이렇게 작성하면 더 좋을 거 같은데.
글을 작성하는 시점(v3.6.0)까지는 위와 같이 입력하면 앞에 스트링은 무시되고 ${env.STAGE}만 입력되는 거 같아요.</p>

<pre class="legacy-code"><code class="language-javascript">// ex.
bucketName: &quot;falsy-exemple-s3-${env.STAGE}&quot; // $ env STAGE=dev ...
=&gt; bucketName: &quot;dev&quot;</code></pre>
<h3>2. 커맨드</h3>
<p class="basic-text-box">
  이제 배포 커맨드를 입력할때 환경 변수로 선언한 애들을 모두 입력해주면 된답니다.</p>

<pre class="legacy-code"><code class="language-javascript">$ env BUCKET_NAME=falsy-exemple-s3-dev CROUDFRONT_ID=aaaaa ... npx serverless</code></pre>
<h3>3. 간단히 하기</h3>
<p class="basic-text-box">
  그런데 이렇게 하면 너무 커맨드가 길어져서 불편한데요. 많은 방법들이 있겠지만,
한 예로 'env-cmd' 라이브러리를 쓰면 조금 편하게 설정할 수 있답니다.
<a href="https://www.npmjs.com/package/env-cmd" target="_blank" rel="noopener noreferrer">https://www.npmjs.com/package/env-cmd</a></p>

<pre class="legacy-code"><code class="language-javascript">// env-cmd 설치
$ npm install env-cmd</code></pre>
<pre class="legacy-code"><code class="language-javascript">// .env-cmdrc 파일 생성
{
  &quot;dev&quot;: {
    &quot;BUCKET&quot;: &quot;falsy-exemple-s3-dev&quot;,
    &quot;CROUDFRONT_ID&quot;: &quot;aaaaa&quot;,
    &quot;DEFAULT_LAMBDA&quot;: &quot;falsy-exemple-default-lambda-dev&quot;,
    &quot;API_LAMBDA&quot;: &quot;falsy-exemple-api-lambda-dev&quot;
  },
  &quot;prod&quot;: {
    &quot;BUCKET&quot;: &quot;falsy-exemple-s3-prod&quot;,
    &quot;CROUDFRONT_ID&quot;: &quot;bbbbb&quot;,
    &quot;DEFAULT_LAMBDA&quot;: &quot;falsy-exemple-default-lambda-prod&quot;,
    &quot;API_LAMBDA&quot;: &quot;falsy-exemple-api-lambda-prod&quot;
  }
}</code></pre>
<h3>4. 커맨드</h3>
<pre class="legacy-code"><code class="language-javascript">// dev 배포
$ env-cmd -e dev npx serverless
// prod 배포
$ env-cmd -e prod npx serverless</code></pre>
<h3>5. 끝으로</h3>
<p class="basic-text-box">
  이전 글에도 적었던 내용이긴 한데, 만약 한번 배포를 해서 .serverless, .serverless_nextjs 디렉토리가 생선된 상태면 수정된 serverless.yml 파일로 배포가 되지 않을 수 있어요.
그래서 다른 스테이지로 배포할 땐 .serverless, .serverless_nextjs 를 지워주고 다시 배포해야 합니다.
package.json 파일을 예로 들면</p>

<pre class="legacy-code"><code class="language-javascript">// package.json
{
  ...

  &quot;scripts&quot;: {
    &quot;start&quot;: &quot;next&quot;,
    &quot;clear&quot;: &quot;rm -r .serverless &amp;&amp; rm -r .serverless_nextjs&quot;,
    &quot;deploy-dev&quot;: &quot;env-cmd -e dev npx serverless&quot;,
    &quot;reDeploy-dev&quot;: &quot;npm run clear &amp;&amp; npm run deploy-dev&quot;,
    &quot;deploy-prod&quot;: &quot;env-cmd -e prod npx serverless&quot;,
    &quot;reDeploy-prod&quot;: &quot;npm run clear &amp;&amp; npm run deploy-prod&quot;
  }

  ...
}</code></pre>
<p class="basic-text-box">
  위와 같이 설정하였다면, 처음 배포할 때는 '$ npm run deploy-dev'로 하고 다음부터는 '$ npm run reDeploy-dev' 로 하면 되겠죠?</p>
