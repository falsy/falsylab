					간단하게 PHP로 AWS S3에 파일을 업로드하는 방법을 정리해보려 합니다.
<h3>1. AWS SDK FOR PHP 설치</h3>
<p class="basic-text-box">
					AWS에서는 AWS SDK를 설치할 수 있는 3가지 방법을 안내하고 있습니다.

<p class="left-line-box">
				AWS SDK PHP 참고 : <a href="https://docs.aws.amazon.com/aws-sdk-php/v3/guide/getting-started/installation.html" target="_blank" rel="noopener noreferrer">https://docs.aws.amazon.com/aws-sdk-php/v3/guide/getting-started/installation.html</a>

<p class="basic-text-box">
					저는 이미 FTP를 연결해서 사용하고 있어서 위 방법 중 3번 zip 파일을 다운로드 받아 FTP를 이용하여 업로드 하였습니다.
<pre class="legacy-code"><code class="language-default">파일 구성
- Aws
- GuzzleHttp
- JmsPath
- Psr
aws-autoloader.php
CHANGELOG.md
LICENSE.md
NOTICE.md
READEME.md</code></pre>
<h3>2. PHP 코드 작성</h3>
<pre class="legacy-code"><code class="language-php">&lt;?php
define(&#x27;S3_KEY&#x27;, &#x27;.....&#x27;);
define(&#x27;S3_SECRET_KEY&#x27;, &#x27;.....&#x27;);
define(&#x27;BUCKET&#x27;, &#x27;.....&#x27;);
include_once(&#x27;aws/aws-autoloader.php&#x27;);
// 앞서 다운로드한 SDK 파일의 autoloader를 불러옵니다.

use Aws\S3\S3Client;
use Aws\S3\Exception\S3Exception;
// S3 파일 업로드에 필요한 클래스를 불러옵니다.

$s3Client = S3Client::factory(array(
  &#x27;region&#x27; =&gt; &#x27;ap-northeast-2&#x27;,
  &#x27;version&#x27; =&gt; &#x27;latest&#x27;,
  &#x27;signature&#x27; =&gt; &#x27;v4&#x27;,
  &#x27;key&#x27;    =&gt; S3_KEY,
  &#x27;secret&#x27; =&gt; S3_SECRET_KEY
));
// AWS IAM 에서 등록한 사용자의 Key와 Secret key로 서울 리전(&#x27;ap-northeast-2&#x27;)의 S3로 접근합니다.

$file_url = &#x27;https://cheolguso.com/wp-content/themes/Cheolguso/img/logo200.png&#x27;;
$s3_path = &#x27;/img/logo.png&#x27;;
$file_data = file_get_contents($file_url);

$s3Client-&gt;putObject(array(
  &#x27;Bucket&#x27; =&gt; BUCKET,
  &#x27;Key&#x27;    =&gt; $s3Path,
  &#x27;Body&#x27;   =&gt; $file_data,
  &#x27;ACL&#x27;    =&gt; &#x27;public-read&#x27;
));
// 이미지 파일(&#x27;https://falsy.me/img/logo.png&#x27;)을 S3버킷의 img디렉토리 안에 저장합니다.
?&gt;</code></pre>
<h3>3. 마치며</h3>
<p class="basic-text-box">
					사실 특별한 코드가 있는건 아니지만,
서울 리전을 사용하면 서명 버전을 v4 만 사용이 가능하다고 하여 factory를 선언할때 조금 헤맷던거 같습니다.

<p class="left-line-box">
				S3 region 참고 : <a href="https://docs.aws.amazon.com/ko_kr/general/latest/gr/rande.html#s3_region" target="_blank" rel="noopener noreferrer">https://docs.aws.amazon.com/ko_kr/general/latest/gr/rande.html#s3_region</a>

<p class="basic-text-box">
					인터넷으로 통해 검색 하였을때에는 아래와 같이 factory를 선언하는 경우를 종종 본거 같은데, (factory의 버전에 따른 차이 때문인지?) 아래의 선언으로는 서명 버전 오류가 출력되었습니다.
<pre class="legacy-code"><code class="language-php">&lt;?php
$s3Client = S3Client::factory(array(
  &#x27;region&#x27; =&gt; &#x27;ap-northeast-2&#x27;,
  &#x27;version&#x27; =&gt; &#x27;latest&#x27;,
  &#x27;credentials&#x27; =&gt; array(
    &#x27;key&#x27; =&gt; &#x27;*********&#x27;,
    &#x27;secret&#x27; =&gt; &#x27;***********************&#x27;
  )
));
?&gt;</code></pre>
<p class="basic-text-box">
					그리고 Wordpress 플러그인 ‘Amazon Web Service’ 의 코드를 살펴보던 중 ‘signature’ 의 값에 ‘v4’을 넣어주는 것을 보고 똑같이 적용하고, 실행해보니 정상 동작하는 것을 확인하였습니다.
<pre class="legacy-code"><code class="language-php">&lt;?php

  &#x27;signature&#x27; =&gt; &#x27;v4&#x27;,
  &#x27;key&#x27;    =&gt; &#x27;**********&#x27;,
