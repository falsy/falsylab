<p class="basic-text-box">
  오늘은 FCM(Firebase Cloud Messaging)을 사용해서 웹에서 알림을 수신하는 방법을 적어보려합니다~</p>
<p class="left-line-box">
  파이어베이스 프로젝트는 생성 되었다고 가정하고..</p>

<h3>1. 파이어베이스 프로젝트 설정</h3>
<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-1.jpg" alt=""></figure>
<p class="basic-text-box">
  왼쪽에 톱니바퀴 아이콘을 눌러서 '프로젝트 설정' 페이지로 이동 후 스크롤을 내려서 &lt;/&gt; 아이콘을 선택해서 웹 플랫폼을 선택해 줍니다.</p>
<p class="basic-text-box">
  그리고 적당한 이름을 작성해주시고 '앱 등록'을 합니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-2.jpg" alt=""></figure>
<p class="basic-text-box">
  그럼 위와 같이 코드들이 나오는데, 'firebaseConfig' 값들을 이따가 코드를 작성할때 해당 설정값에 넣어줄 거에요.</p>
<p class="basic-text-box">
  다음으로 '프로젝트 설정' 페이지 상단에 '클라우드 메시징' 탭으로 이동한 후 아래로 스크롤을 내려서</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-3.jpg" alt=""></figure>
<p class="basic-text-box">
  'Generate key pair' 버튼을 눌러서 인증서 키 값을 만들어 줍니다.</p>
<p class="left-line-box">
  이 키값은 이따가 토큰 요청하는 코드에 사용할 거에요.</p>

<h3>2. nextjs에서 알림 수신 설정하기</h3>
<p class="left-line-box">
  테스트에 사용된 코드는 <a href="https://github.com/falsy/blog-post-example/tree/master/next-js-fcm" target="_blank" rel="noopener noreferrer">https://github.com/falsy/blog-post-example/tree/master/next-js-fcm</a>에서 모두 확인하실 수 있습니다.
(저는 간단하게 next, react, firebase 를 설치하였습니다.)</p>
<p class="basic-text-box">
  우선 nextjs 사용하니까 패키지 가장 밖에 public 디렉토리를 만들어 주시고 아래와 같이 'firebase-messaging-sw.js' 파일을 추가해 줍니다.</p>

<pre class="legacy-code"><code class="language-javascript">// /public/firebase-messaging-sw.js
importScripts(&#x27;https://www.gstatic.com/firebasejs/9.14.0/firebase-app-compat.js&#x27;);
importScripts(&#x27;https://www.gstatic.com/firebasejs/9.14.0/firebase-messaging-compat.js&#x27;);

// 이곳에 아까 위에서 앱 등록할때 받은 &#x27;firebaseConfig&#x27; 값을 넣어주세요.
const config = {
  apiKey: &#x27;&#x27;,
  authDomain: &#x27;&#x27;,
  projectId: &#x27;&#x27;,
  storageBucket: &#x27;&#x27;,
  messagingSenderId: &#x27;&#x27;,
  appId: &#x27;&#x27;
};

// Initialize Firebase
firebase.initializeApp(config);

const messaging = firebase.messaging();</code></pre>
<p class="basic-text-box">그리고</p>

<pre class="legacy-code"><code class="language-javascript">// /src/pages/index.js
import React, { useEffect } from &#x27;react&#x27;
import { initializeApp } from &#x27;firebase/app&#x27;
import { getMessaging, onMessage, getToken } from &#x27;firebase/messaging&#x27;

const Index = () =&gt; {

  const onMessageFCM = async () =&gt; {
    // 브라우저에 알림 권한을 요청합니다.
    const permission = await Notification.requestPermission()
    if (permission !== &#x27;granted&#x27;) return 

    // 이곳에도 아까 위에서 앱 등록할때 받은 &#x27;firebaseConfig&#x27; 값을 넣어주세요.
    const firebaseApp = initializeApp({
      apiKey: &#x27;&#x27;,
      authDomain: &#x27;&#x27;,
      projectId: &#x27;&#x27;,
      storageBucket: &#x27;&#x27;,
      messagingSenderId: &#x27;&#x27;,
      appId: &#x27;&#x27;
    })

    const messaging = getMessaging(firebaseApp)

    // 이곳 vapidKey 값으로 아까 토큰에서 사용한다고 했던 인증서 키 값을 넣어주세요.
    getToken(messaging, { vapidKey: &#x27;&#x27; }).then((currentToken) =&gt; {
      if (currentToken) {
        // 정상적으로 토큰이 발급되면 콘솔에 출력합니다.
        console.log(currentToken)
      } else {
        console.log(&#x27;No registration token available. Request permission to generate one.&#x27;)
      }
    }).catch((err) =&gt; {
      console.log(&#x27;An error occurred while retrieving token. &#x27;, err)
    })

    // 메세지가 수신되면 역시 콘솔에 출력합니다.
    onMessage(messaging, (payload) =&gt; {
      console.log(&#x27;Message received. &#x27;, payload)
    })
  }

  useEffect(() =&gt; {
    onMessageFCM()
  }, [])

  return (
    &lt;div&gt;
      &lt;h1&gt;hello world&lt;/h1&gt;
    &lt;/div&gt;
  )
}

export default Index</code></pre>
<p class="basic-text-box">저는 간단하게, 이렇게 코드를 구성하였습니다~</p>

<h3>3. 알림 테스트</h3>
<p class="basic-text-box">
  위와 같이 코드를 다 작성이 되면 실행한 후 '개발자도구' &gt; '콘솔'로 이동해서
로그로 출력하게 했던 토큰값을 복사해 둡니다.</p>
<p class="basic-text-box">
  다시 파이어베이스로 돌아가서 '참여' 매뉴에 있는 'messaging'을 선택합니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-4.jpg" alt=""></figure>
<p class="basic-text-box">
  위와 같이 '첫 번째 캠페인 만들기' 버튼을 선택합니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-5.jpg" alt=""></figure>
<p class="basic-text-box">
  'Firebase 알림 메시지'를 선택한 후 '만들기' 버튼을 선택합니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-6.jpg" alt=""></figure>
<p class="basic-text-box">
  적당히 '알림 제목'과 '알림 텍스트'를 입력하시고 오른쪽에 '테스트 메시지 전송' 버튼을 눌러줍니다.</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-7.jpg" alt=""></figure>
<p class="basic-text-box">
  아까 콘솔창에 출력시켜서 복사해두었던 토큰 값을 넣어준 후 '+' 버튼을 누르고, 체크한 후
테스트 버튼을 누르면!</p>

<figure><img style="max-width: 100%;" src="/wp-content/uploads/2022/11/fb-8.jpg" alt=""></figure>
<p class="basic-text-box">
