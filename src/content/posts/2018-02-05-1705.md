      <div id="review_text">
        <p class="left-line-box">
          자바스크립트의 this 는 선언 시점이 아닌 호출에 따라, 그리고 어떻게 호출했는지에 따라 가리키는 것이 달라집니다.
이글은 짧게나마, 설명보단 간단한 예로 몇가지 상황에 대해 정리해보려 합니다.
        </p>
        <h3>1.</h3>
 
<pre class="legacy-code"><code class="language-javascript">var aaa = &#x27;aaa&#x27;;
function a() {
  console.log(this.aaa);
}
a();
// &#x27;aaa&#x27;;</code></pre> 

<pre class="legacy-code"><code class="language-javascript">&quot;use strict&quot;;
var aaa = &#x27;aaa&#x27;;
function a() {
  console.log(this.aaa);
}
a();
// TypeError</code></pre>
        <p class="basic-text-box">
          가장 단순한 함수에서의 this는 전역을 가르킵니다. 전역에서의 변수 <span class="bg-point-text">var aaa</span>는 <span class="bg-point-text">window.aaa</span>와 같습니다(브라우저). 하지만 엄격모드('use strict') 에서는 선언되지 않은 프로퍼티로 타입 오류입니다.
        </p>

        <h3>2.</h3>
 
<pre class="legacy-code"><code class="language-javascript">var a = {
  aaa: &#x27;aaa&#x27;,
  bbb: function() {
    console.log(this.aaa);
  }
};
a.bbb();
// &#x27;aaa&#x27;;

var a = {
  aaa: &#x27;aaa&#x27;,
  bbb: {
    aaa: &#x27;ccc&#x27;,
    ddd: function() {
      console.log(this.aaa);
    }
  }
};
a.bbb.ddd();
// &#x27;ccc&#x27;;</code></pre> 

        <p class="basic-text-box">
          객체의 프로퍼티에 값으로 있는 함수 (메소드)의 this는 자신히 속한 객체를 가르킵니다.
        </p>

        <h3>3.</h3>
 
<pre class="legacy-code"><code class="language-javascript">function a() {
  console.log(this.aaa);
}
var aaa = {
  aaa: &#x27;aaa&#x27;
};
a.call(aaa);
// &#x27;aaa&#x27;</code></pre> 

        <p class="basic-text-box">
          call(), apply() 메서드를 이용하여 함수를 호출하면 this를 지정한 객체로 바인딩 할 수 있습니다.
        </p>
        <h3>4.</h3>
 
<pre class="legacy-code"><code class="language-javascript">function a(b) {
  this.bbb = b;
}
var aaa = new a(&#x27;bbb&#x27;);
console.log(aaa.bbb);
// &#x27;bbb&#x27;</code></pre> 

        <p class="basic-text-box">
          new 생성자로 선언한 함수 역시 만들어지는 객체로 this가 가르킵니다.
        </p>
        <h3>5.</h3>
 
<pre class="legacy-code"><code class="language-javascript">var a = {
  aaa: &#x27;aaa&#x27;,
  bbb: function() {
    (function() {
      console.log(this.aaa);
    })();
  }
}
a.bbb();
// undefined
// 엄격모드(&quot;use strict&quot;) 에서는 TypeError</code></pre> 

        <p class="basic-text-box">
          적당한 예인지는 모르겠지만 Amtn, 객체의 메서드 함수 안에 있는, 함수의 this가 객체를 가르킨다고 생각하거나 그렇게 기대하는 경우가 많은데, 기본적으로 단일 함수의 this는 전역을 가르키기 때문에 undefined, 엄격모드에서는 타입오류 입니다.
        </p>
 
<pre class="legacy-code"><code class="language-javascript">var a = {
  aaa: &#x27;aaa&#x27;,
  bbb: function() {
    var self = this;
    (function() {
      console.log(self.aaa);
    })();
  }
}
a.bbb();
// &#x27;aaa&#x27;</code></pre> 

        <p class="basic-text-box">
          그리하여 일반적으로 <span class="bg-point-text">var self (또는 _this, that ..)</span> 등의 임의의 변수로 this를 참조하여 사용하는 경우가 많았던것 같습니다.
        </p>
        <h3>6.</h3>
        <p class="basic-text-box">
          ES6에서 새롭게 추가된 구문으로 화살표 함수에서는 위에서 기대하던대로 자신만의 this를 생성하지 않고 this를 감싸고 있는 컨텍스트로부터 대상을 찾습니다.
        </p>
 
<pre class="legacy-code"><code class="language-javascript">var a = {
  aaa: &#x27;aaa&#x27;,
  bbb: function() {
    (() =&gt; {
      console.log(this.aaa);
    })();
  }
}
a.bbb();
// &#x27;aaa&#x27;</code></pre>
